# 분석 사진·칸 고르기 기준

부위 분석(립·블러셔·눈썹·섀도·아이라인)은 단계 직전·직후 사진을 얼굴 지도에 펴고 칸마다 가운데 값을 내서 견준다. 이 문서는 그 전에 쓸 사진과 쓸 칸을 고르는 기준이다. 사진 판정은 `app/tasks/area/landmarks/frame_checker.py`, 가림 찾기는 `app/tasks/area/landmarks/occlusion_finder.py`, 사진 고르기와 칸 빼기는 `app/tasks/area/parts/area_preparation.py`가 한다.

기준값은 시험 영상(GO지승 `VxAXD6PP76I`)에서 서비스가 실제로 쓰는 사진 361장(13개 단계의 직전·직후 묶음)의 분포로 정했다. 비교 결과는 [docs/experiments](../../docs/experiments/README.md)에 둔다.

## 말

| 말 | 뜻 |
|---|---|
| 칸 | 얼굴 지도(1024×1024)의 한 칸. 사진마다 얼굴 점으로 펴서, 같은 칸은 얼굴의 같은 자리다 |
| 사진 묶음 | 한 단계의 직전 또는 직후 시간 안에서 고른 사진들 |
| 범위 | 부위 분석이 바른 곳을 찾아보는 칸들. 부위마다 정해져 있다(예: 섀도는 눈 둘레 울타리) |
| 가림 | 피부·눈썹·입술·눈 자리에 얼굴이 아닌 것이 보이는 곳 |
| 모름 칸 | 묶음의 모든 사진에서 가려져 색을 알 수 없는 칸 |
| 눈 뜬 정도 | 눈마다 둘레 점 6개로 잰 (세로 길이 두 개의 평균) ÷ 가로 길이 중 작은 쪽. 뜬 눈 약 0.30~0.40, 감은 눈 0.1 미만 |

## 가림

| 항목 | 기준 |
|---|---|
| 가림으로 보는 것 | 얼굴이 아닌 것은 종류와 상관없이 가림이다. 손, 붓·펜슬·퍼프 같은 도구, 팔레트·제품, 머리카락, 영상에 얹힌 자막·글자 |
| 가림으로 보지 않는 것 | 손 그림자. 넓은 밝기 변화는 조명 보정이, 잠깐 진 그림자는 가운데 값이 거른다. 그림자를 가림으로 보면 어두워지는 화장(눈썹·아이라인·쉐딩)까지 지울 수 있다 |
| 찾는 방법 | 가림 찾기 모델(`app/weights/occlusion_bisenet.v1.onnx`). 얼굴 분할 BiSeNet에 가림 칸을 더해 학습했다. 출처와 시험 결과는 [app/weights/README.md](../app/weights/README.md)에 있다 |
| 둘레 여유 | 0칸(`OCCLUSION_MARGIN_CELLS`). 합성 시험에서 모델은 진짜 가림 픽셀의 95.3%를 잡는다. 둘레를 1px 넓히면 96.6%로 1.3%p 느는 대신 가림이 아닌데 칠한 넓이가 14%에서 20%로 는다. 남는 얇은 테두리는 가운데 값이 거른다 |

가린 칸은 그 사진에서만 빼고, 같은 칸이 보이는 다른 사진들의 가운데 값으로 정한다. 지운 자리를 그려 넣지 않는다. 그려 넣은 색은 실제로 찍힌 색이 아니라서 바른 곳 판정을 흐린다.

빼기는 사진마다 가운데 값을 내기 전에 한다. 그래서 부위 분석이 지도를 흐려도 가린 값이 번지지 않는다.

## 사진을 빼는 조건

| 조건 | 적용 부위 | 기준 | 근거 |
|---|---|---|---|
| 얼굴이 작음 | 전부 | 얼굴 가로 256px 미만 | |
| 고개 돌림 | 전부 | 좌우·위아래 각도 20° 초과 | |
| 부위가 화면 밖 | 그 부위 | 부위 점이 하나라도 화면 밖 | |
| 크기 튐 | 전부 | 앞뒤 1초 사진 얼굴 가로 가운데 값 대비 0.8~1.2 밖 | |
| 가림이 많음 | 그 부위 | 범위의 20% 초과를 가림(`OCCLUDED_MAX`) | 시험 영상에서 20%를 넘은 3장(696.2~696.4초)은 모두 팔레트를 얼굴 앞에 들어 초점이 팔레트에 간 사진이었다. 큰 물체가 얼굴 앞에 있으면 남은 칸도 그림자·초점에 끌리기 쉽다 |
| 눈 감음 | 섀도·아이라인 | 눈 뜬 정도 0.2 미만(`EYE_OPEN_MIN`) | 시험 영상에서 0.1 미만은 감은 눈, 0.12~0.19는 반쯤 감은 눈이었고, 0.2 이상은 펜슬을 대고 내려다본 것까지 모두 뜬 눈이었다. 감은 눈꺼풀은 뜬 눈과 색이 달라 바른 곳으로 잡힌다. 다른 부위에는 그대로 쓴다 |
| 흐림 | 두지 않음 | | 아래 「한계」 |

얼굴이 작음·고개 돌림은 사진 판정 결과에 이유를 남긴다. 나머지로 뺀 사진은 부위 분석에서만 빠지고, 남은 사진이 없으면 그 하위 단계가 `noUsableFrame` 이유로 기본 영역(`template`)이 된다.

## 직전·직후 크기 맞추기

확대 사진이라는 이유만으로 빼지 않는다. 얼굴 지도로 펴면 확대 사진도 같은 칸이 얼굴의 같은 자리다.

대신 직전 묶음과 직후 묶음의 크기를 맞춘다(`match_sizes`). 묶음마다 얼굴 가로 가운데 값을 내고 비율(직후 ÷ 직전)이 0.8~1.25(`SIZE_MATCH_RANGE`) 밖이면, 사진이 더 많은 묶음에서 다른 쪽 가운데 값과의 비율이 범위 안인 사진만 남긴다. 남는 사진이 없으면 그 하위 단계는 `faceSizeMismatch` 이유로 기본 영역(`template`)이 된다.

시험 영상에서는 s19(0.77)만 범위 밖이었다. 직전 사진이 모두 확대 장면(얼굴 가로 약 1,011px, 직후 약 774px)이라 맞출 사진이 없어 두 눈 모두 기본 영역이 된다. 0.87인 s8은 판정에서 합격한 단계라 범위를 그보다 좁히지 않았다.

## 사진이 모자랄 때

| 경우 | 처리 |
|---|---|
| 한 칸이 묶음의 모든 사진에서 가려짐 | 그 칸은 모름 칸으로 두고 부위 분석에서 뺀다 |
| 범위의 절반 넘게 모름 칸(`UNKNOWN_MAX`, `mostly_unknown`), 또는 묶음에 쓸 사진이 없음 | 그 하위 단계는 `noUsableFrame` 이유로 기본 영역(`template`)이 된다. 절반 넘게 모르는 범위에서 찾은 곳은 믿기 어렵다 |

시험 영상에서는 모든 사진에서 가려진 칸이 어느 묶음에서나 0%였다.

## 한계

- 흐린 사진은 빼지 않는다. 시험 영상에서 가린 칸을 뺀 얼굴 칸의 선명도(라플라시안 분산)가 영상 가운데 값의 0.1배 미만인 12장은 모두 팔레트에 초점이 간 사진이었다. 그런데 선명도 수준은 영상마다 달라서 고정 값으로는 다른 영상에 못 옮기고, 영상 가운데 값을 내려면 영역을 만들기 전에 사진을 한 번 더 읽어야 한다. 이 장면들은 가린 칸이 이미 빠지므로 이번에는 두지 않았다.
- 진한 손 그림자가 오래 지는 영상에서는 그림자가 남을 수 있다.
- 기준은 시험 영상 하나(GO지승 `VxAXD6PP76I`)로 정했다. 이 영상은 조명이 정면에서 부드러워 그림자가 옅다.
