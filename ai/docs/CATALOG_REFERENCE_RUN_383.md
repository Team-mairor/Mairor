# 기준 세트 채움률 1차 측정 (S15P31A306-383)

2026-11-09, 공식 홈 11곳에서 색조 제품 3개씩을 `collect --render --colors --vision`으로 수집해
`tools/report_catalog_colors.py brands`로 낸 숫자다. 측정은 "상세 이미지 차트 연결"을 넣은 코드로 했다.

- 제품은 카테고리 목록의 앞쪽에서 이름에 틴트·립·섀도·블러셔·쿠션·컨실러 같은 말이 있고 세트·기획이
  아닌 것을 골랐다. 그런 제품이 없으면 목록 앞쪽을 그대로 썼다(넘버즈인은 스킨케어 위주라 색조가 아니다).
- "된 브랜드": 호수의 70% 이상이 쓸 수 있는 색(`OPTION_IMAGE`·`SINGLE_SHADE_PRODUCT`·`LABEL_IN_IMAGE`이고
  사진 색은 품질이 임계값 이상). **임계값은 백엔드가 정하는 값이라 두 가지로 보여 준다.**
- 브랜드당 제품 3개라 표본이 작다. 비율은 방향을 보는 용도이고 확정 수치가 아니다.

## 읽는 법

- **임계값에 따라 결과가 크게 갈린다.** 0.3에서는 2곳, 0.5에서는 1곳이 된다. 상세 차트 칸은 입술·피부에 바른
  발색 컷이 많아 품질이 0.4로 제한되고(피부색이 섞이므로), 디어달리아 옵션 사진도 대부분 0.3~0.5 사이다.
  백엔드 `catalog.color.min-quality.PRODUCT_PHOTO`를 정할 때 이 분포를 근거로 쓴다. 사람이 라벨링한
  실사진 기준 세트로 정확도와 함께 정하는 것이 원칙이다.
- **상세 차트로 새로 색을 얻은 브랜드**(`LABEL_IN_IMAGE`): 투쿨포스쿨, 디어에이, 하트퍼센트, 롬앤, 힌스, 퓌.
  이 방식을 넣기 전에는 이 브랜드들이 거의 0%였다(293 실측: 11곳 중 2곳).
- **목표 비율**은 이 1차 측정으로 정하지 않는다. 임계값이 먼저 정해져야 의미가 있다.

## 못 채운 이유 (경고 코드로 본 것)

| 이유 | 브랜드 | 설명 |
| --- | --- | --- |
| 호수 이름에 번호가 없음(`SHADE_NO_NUMBER`) | 정샘물, 넘버즈인, 퓌 일부 | 번호로 잇는 방식을 쓸 수 없다. 이름 기반 연결은 오연결 위험이 커서 하지 않았다. |
| 색 이미지가 아님(`NOT_A_COLOR_IMAGE`) | 정샘물, 디어에이, 롬앤 | 호수 이미지가 모델·연출 컷이다. |
| 호수 번호 중복(`SHADE_NUMBER_DUPLICATE`) | 힌스 | 한 상품 안에 같은 번호가 둘 이상이라 잇지 않았다. |
| 칸을 읽었지만 색을 못 믿음(`CHART_CELL_UNREADABLE`) | 힌스, 디어에이, 롬앤, 투쿨포스쿨 | 칸 색이 한 색으로 모이지 않거나 줄의 칸 수와 칩 수가 달랐다. |
| 번호가 같은 칸이 서로 다른 색(`CHART_NUMBER_AMBIGUOUS`) | 하트퍼센트 | 같은 번호의 칸이 둘 이상이고 색이 달라 잇지 않았다. |
| 이미지 받기 실패(`IMAGE_FAILED:HTTP_ERROR`) | 하트퍼센트 | 옵션 이미지 요청이 재시도 끝에 모두 실패했다(일시적일 수 있다). |
| 호출 상한(`CHART_OVERVIEW_LIMIT`) | 넘버즈인 | 색조가 아닌 제품의 상세 이미지가 많아 상한에 닿았다. |
| 차단(`BLOCKED`) | 바닐라코 | 이미지 서버 `403`. 우회하지 않는다. |

## 합친 코드로 다시 확인 (2026-11-09)

master에 합친 뒤 실제 사이트에서 두 상품을 다시 수집했다.

- 롬앤 `더 쥬시 래스팅 틴트`: 호수 23개 중 18개를 `LABEL_IN_IMAGE`로 채웠다. 이전 측정과 같다.
- 하트퍼센트 `도트 온 무드 올 데이 립 쉐이퍼`: 호수 5개 모두 `LABEL_IN_IMAGE`로 채웠다. 칩 차트라 `SWATCH_CHIP`이고 품질은 0.53~0.58이다(롬앤 같은 발색 컷의 0.4 제한에 걸리지 않는다).
- 하트퍼센트의 `IMAGE_FAILED:HTTP_ERROR`는 일시적인 실패가 아니었다. 이 제품의 대표 이미지 주소(`visualkorea0.cafe24.com/.../em_3.png`)가 사이트 쪽에서 죽은 주소라 접속이 안 된다(`ConnectError`). 이 이미지는 호수 색에 쓰이지 않고 상세 차트에서 색을 얻으므로 결과에는 영향이 없다.
