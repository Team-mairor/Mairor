# 바른 곳 찾기 모델 학습 영상과 사진

바른 곳 찾기 모델을 학습시킬 영상을 정하고, 단계 경계 앞뒤 사진을 모은 기록이다 (S15P31A306-426). 정답지는 여기서 만들지 않는다. 스크립트와 실행 순서는 [ai/tools/guide_area_training/README.md](../../ai/tools/guide_area_training/README.md)에 있다.

## 요약

- 영상 8개(채널 8개, 서로 다른 사람)에서 분석하는 단계 69개의 직전·직후 사진 8,886장(1.12GB)을 받았다. 학습 영상 6개, 검증 영상 2개다. 시험 영상(GO지승 `VxAXD6PP76I`)은 넣지 않았다.
- 사람이 사진을 보고 고르거나 적은 것은 없다. 단계표는 운영과 같은 영상 처리기(`video-processor`)가 뽑았고, 사진은 정해진 구간·간격으로 뽑았고, 쓸 사진은 서비스 사진 판정 코드와 기준값으로 골랐다.
- 묶음(단계 시작 앞 5초·끝 뒤 5초) 안 사진 7,097장 중 판정 `ok`가 5,393장, 부위 조건과 흐림까지 통과한 쓸 사진이 4,533장이다. 2초 안에서 한 장씩만 남기면 322장이다.
- 직전·직후 양쪽에 쓸 사진이 있는 단계는 69개 중 62개다. 학습 쪽은 눈썹 3단계·아이라인 3단계로 적다.
- 가림 찾기 모델 학습 문서의 "다른 메이크업 영상 5개"는 실제로 4개다. 로컬 샘플 local_01은 `eFzG30avtOI`, local_02는 `vWhW8hSlL54`와 같은 영상이다.

## 사진

### 뽑는 규칙

| 규칙 | 값 | 이유 |
|---|---|---|
| 묶음 | 분석하는 단계의 시작 앞 5초(직전), 끝 뒤 5초(직후) | 서비스의 직전·직후 창(부위마다 1~4초)을 모두 덮는다. 창 길이를 바꿔도 사진을 다시 받지 않는다 |
| 뽑는 구간 | 묶음 양쪽에 1초씩 더함 | 사진 판정이 얼굴 크기를 앞뒤 1초 사진과 견준다. 영상 처리기가 사진을 뽑는 방식과 같다 |
| 간격 | 프레임 번호가 `round(fps / 10)`의 배수 | BE 프레임 계획(`FramePlan`)·영상 처리기와 같다. 초당 약 10장(23.98fps는 12장) |
| 형식 | 원본 1080p, JPEG `-q:v 2`, 파일 이름은 프레임 번호 6자리 | BE·영상 처리기와 같다 |
| 영상 파일 | `bestvideo[height<=1080][vcodec^=avc1]` | 영상 처리기와 같은 형식으로 받는다(`processor.clients.youtube`) |

기존 `a306-train-data`의 가림 학습 사진은 얼굴이 보이는 구간을 5초마다 찍은 것이라 단계 경계 앞뒤가 비어 있다. 그래서 새로 뽑았다. 계획한 장수와 뽑은 장수는 영상 8개 모두 같았다.

### 판정

서비스 코드와 기준값을 그대로 썼다(`judge_frames.py`). 얼굴 점 찾기(`build_landmarks`) → 사진 판정(`check_frames`) → 부위별 고르기(`usable_rows`, 앞뒤 단계 시간은 `within_step`) → 흐린 사진 빼기(`drop_blurry`, 가림 찾기 모델 포함) 순서다. 기준은 [분석 사진·칸 고르기 기준](../../ai/docs/FRAME_SELECTION.md)과 같다.

## 재현 방법

`ai/` 폴더에서 [도구 안내문](../../ai/tools/guide_area_training/README.md)의 순서대로 돌린다. 영상·사진·판정 결과는 git에 없고 작업 폴더(`GUIDE_AREA_TRAIN_DIR`)에 둔다. 단계표는 GMS 답이라 다시 뽑으면 단계 수와 시각이 달라질 수 있다. 이번에 쓴 단계표는 작업 폴더의 `<영상 ID>/guide_request.json`이다.

## 한계

- 단계표는 영상 처리기가 뽑은 그대로다. 단계 끝이 실제로 바르기를 마친 때보다 이르거나 늦으면 직전·직후 묶음에 손·도구가 얼굴에 닿은 사진이 들어간다. 가린 칸은 서비스처럼 사진마다 빼지만, 단계 시각 자체는 확인하지 않았다.
- 학습 쪽 눈썹(양쪽 있는 단계 3개)·아이라인(3개)이 적다.
- 검증 2개 영상이 쓸 사진의 43.5%(1,972 / 4,533)다. 나눔 규칙이 영상 길이·단계 수를 보지 않아서다.
- 영상 8개 가운데 2개(`BJOEa0LjLYw`, `tSBaf010odM`)는 남자 메이크업 영상이고 립·블러셔·아이라인 단계가 거의 없다.
- 공개 데이터셋은 보지 않았다.
