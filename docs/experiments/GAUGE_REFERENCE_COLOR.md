# 레퍼런스 영상 부위별 색 뽑기: 찾은 영역의 바른 뒤 색 · 바르기 전 색 · 둘레 맨피부 색

가이드 영역을 찾을 때 이미 만드는 단계 직전 · 직후 얼굴 지도에서, 찾은 영역마다 대표 색을 뽑은 기록이다. 색감 · 진하기 게이지의 레퍼런스 기준, 색감 맞추기, 미리보기 레이어의 재료다.

## 요약

- 찾은 영역(`extracted`)마다 **바른 뒤 색 · 같은 칸의 바르기 전 색 · 둘레 맨피부 띠의 직후 색 · 직전 색**을 RGB · HEX · Lab으로 낸다. 좌우 따로 내고, 찾은 쪽 칸만 합친 색도 하나 더 낸다.
- 색은 가이드 영역 결과(`shared/guide-area`)에 넣지 않는다. 단계 기록(`area_step`의 `colors`)과 개발용 파일(`output/area_colors.json`)에만 남는다. **가이드 영역 결과는 색 뽑기를 넣기 전과 바이트까지 같다.**
- 대표 색은 영역 칸의 **채널별 가운데 값(RGB)**, 영역 가장자리는 **깎지 않는다**. 맨피부 띠는 영역에서 **24칸 띄우고 32칸 두께**다.
- 좌우 짝 부위는 두 쪽 모양을 합치거나 한쪽을 뒤집어 보내서, 보낸 모양 안에 그쪽에서 바르지 않은 칸이 섞인다. 색은 **그쪽이 실제로 찾은 칸**에서만 낸다.
- 그쪽에서 못 찾아 반대쪽 모양을 뒤집어 쓴 영역은 `mirrored`로 표시하고 합친 색에서 뺀다. 그 칸의 색은 화장 색이 아니다.
- 색을 못 뽑으면 이유를 남긴다. 기본 가이드 단계는 `noArea`, 직후 사진 사이 흔들림이 전후 색 차이보다 크면 `colorSpread`, 모름 칸을 빼고 20칸이 안 남으면 `tooFewCells`, 지도가 없으면 `noMaps`다.
- 시험 영상(GO지승 VxAXD6PP76I, 35단계)에서 **하위 단계 13개**에 색이 나왔다. 색 뽑기에 든 시간은 2,939초 중 18.2초(0.6%)다.
- **전후 사이 조명 변화가 화장 변화와 비슷한 크기다.** 맨피부 띠의 직전 · 직후 색 차이(가운데 값 2.7)가 영역의 전후 색 차이(3.9)에 가깝다. 진하기는 바른 색 하나가 아니라 맨피부와의 차이로 재야 한다.

## 방법

| 단계 | 내용 | 코드 |
| --- | --- | --- |
| 지도 맡기기 | 부위 분석이 직전 · 직후 지도, 모름 칸, 직후 사진을 부위 이름으로 맡긴다. 밖에서는 아무 일도 하지 않는다 | `area_color.note_maps` |
| 찾은 칸 맡기기 | 좌우 짝 부위에서 그쪽이 찾은 칸, 또는 못 찾아 반대쪽을 뒤집어 썼다는 표시를 보낸 테두리와 함께 맡긴다 | `guide_area_builder.pair_sub_step` · `eyeliner_sub_steps`, `eyeliner_area.used_eyeliner` |
| 색 낼 칸 | 보낸 테두리를 지도 칸으로 되돌리고, 그쪽이 찾은 칸과 겹친 곳만 쓴다. 겹친 칸이 20칸이 안 되면 보낸 모양 전체 | `guide_area_builder._piece` |
| 대표 색 | 칸들의 채널별 가운데 값. 모름 칸은 뺀다 | `area_color.median_color` |
| 맨피부 띠 | 보낸 모양에서 24칸 띄운 32칸 두께. 입술 · 눈 · 눈썹과 그 둘레 4칸, 얼굴 바깥은 뺀다 | `area_color.skin_band` |
| 사진 퍼짐 | 직후 사진을 고르게 12장까지 골라 사진마다 색을 따로 내고, 그 색들이 가운데 색에서 떨어진 Lab 거리의 가운데 값 | `area_color.photo_spread` |
| 색 없음 | 퍼짐 > 바른 뒤 색과 바르기 전 색의 Lab 거리이면 `colorSpread` | `area_color.area_color` |
| 아이라인 | 직후 지도를 따로 만들지 않아(조각마다 만든다), 직후 사진에서 필요한 칸만 가운데 값을 낸다 | `area_color._after_colors` |
| 기록 | 하위 단계 · 부위마다 한 줄, 좌우 둘이면 찾은 쪽을 합친 줄(부위 없음)을 하나 더 | `guide_area_builder.step_colors` |

기록 한 줄의 칸은 `subStepId` · `region` · `mirrored` · `applied` · `before` · `skin` · `skinBefore`(각각 `rgb` · `hex` · `lab`) · `spread` · `photos` · `cells` · `reason`이다.

## 견준 것

시험 영상의 찾은 영역 22개(눈썹 4, 코 쉐딩 2, 아이섀도 6, 아이라인 8, 블러셔 2)로 쟀다. 사람이 고른 정답 없이 아래 지표로 골랐다. 값은 모두 Lab 거리이고 「가운데 값 / 상위 10% / 최대」다.

- **홀짝 재현성**: 직후 사진을 홀짝으로 나눠 각각 낸 색의 거리. 작을수록 사진 고르기에 덜 흔들린다.
- **전후 차이**: 바른 뒤 색과 바르기 전 색의 거리.
- **띠 끌림**: 띠의 전후 변화가 영역의 전후 변화 방향으로 간 비율. 0이면 띠에 화장이 섞이지 않았다.

### 대표 색 내는 법 × 가장자리 깎기

| 후보 | 홀짝 재현성 | 좌우 색 거리 | 전후 차이 |
| --- | --- | --- | --- |
| RGB 가운데 값, 깎지 않음 | 0.39 / 0.79 / 2.41 | 4.15 / 9.28 / 12.59 | 3.87 / 11.91 / 16.72 |
| Lab 가운데 값, 깎지 않음 | 0.39 / 0.65 / 2.64 | 3.86 / 9.27 / 12.23 | 3.43 / 11.00 / 16.61 |
| 변화 큰 절반 칸만, 깎지 않음 | 0.58 / 1.55 / 2.21 | 6.35 / 10.68 / 16.40 | 5.03 / 14.27 / 20.26 |
| RGB 가운데 값, 2칸 깎음 | 0.51 / 1.04 / 2.28 | 4.16 / 10.00 / 13.70 | 3.91 / 12.72 / 17.67 |
| RGB 가운데 값, 4칸 깎음 | 0.48 / 0.89 / 2.23 | 4.28 / 10.95 / 14.24 | 4.24 / 12.15 / 18.57 |
| RGB 가운데 값, 6칸 깎음 | 0.51 / 0.73 / 2.41 | 4.35 / 9.32 / 12.59 | 3.73 / 12.36 / 19.32 |

- RGB와 Lab 가운데 값은 거의 같다. RGB · HEX · Lab이 같은 색 하나를 가리키게 RGB 가운데 값을 골랐다.
- 변화 큰 칸만 고르면 전후 차이는 커지지만 재현성과 좌우 일치가 나빠진다. 고르는 칸이 사진마다 달라져서다.
- 가장자리를 깎아도 재현성이 좋아지지 않는다(0.39 → 0.48~0.51). 깎지 않는다.

- 띠가 영역에 가까우면 번진 화장이 섞인다. 끌림이 2 / 6에서 0.49, 24칸부터 0.1 안팎으로 평평해진다. 부위별로는 블러셔가 24칸부터, 아이섀도가 10칸부터 0 근처다.
- 더 멀리 잡아도 끌림은 더 줄지 않고 영역에서 먼 피부가 된다. 평평해지기 시작하고 띠 재현성이 가장 좋은 24 / 32를 골랐다.
- 코 쉐딩은 어느 간격에서도 끌림이 0.4~0.7이다. 콧대 둘레는 쉐딩이 넓게 퍼지고 그림자가 같이 바뀐다.
- 띠가 없는 영역은 없었다.

### 기본 가이드 단계

못 찾아 기본 가이드를 쓰는 단계에서 살펴볼 범위 전체로 색을 내 봤다. 범위 전체의 전후 차이(가운데 값 1.8)가 띠의 전후 차이(1.9)와 같은 크기라 조명 변화와 구별되지 않는다. 변화가 큰 25% 칸만 고르면 전후 차이가 2~11로 커지지만, 큰 칸을 골랐으니 커진 것이고 바르지 않은 단계에서도 생긴다. 그래서 기본 가이드 하위 단계는 색을 뽑지 않고 `noArea`만 남긴다.

### 그쪽이 찾은 칸만 · 보낸 모양 전체

좌우 짝 부위에서 뒤집어 쓰지 않은 쪽만 쟀다.

| 영상 | 색 낼 칸 | 홀짝 재현성 (가운데 / 상위 10%) | 전후 차이 (가운데 / 상위 10%) | 사진 퍼짐 (가운데) |
| --- | --- | --- | --- | --- |
| 시험 영상 | 찾은 칸만 | 0.47 / 1.88 | 4.54 / 15.13 | 1.15 |
| 시험 영상 | 보낸 모양 전체 | 0.39 / 1.42 | 4.42 / 12.17 | 1.10 |
| RBm4rzufBV0 | 찾은 칸만 | 0.93 / 1.98 | 9.12 / 17.92 | 1.75 |
| RBm4rzufBV0 | 보낸 모양 전체 | 0.93 / 2.17 | 9.12 / 13.59 | 1.57 |

- 보낸 모양 전체로 내면 반대쪽에서만 바른 칸이 섞여 색이 맨피부 쪽으로 끌린다. 진한 영역(상위 10%)의 전후 차이가 12~14에서 15~18로 커진다.
- 재현성은 시험 영상에서 조금 나빠지고(0.39 → 0.47) 다른 영상에서는 같다. 전후 차이에 견준 비율은 두 쪽 모두 0.1 안팎이다.
- 치우침이 없는 「찾은 칸만」을 골랐다.

### 뒤집어 쓴 쪽

시험 영상 눈썹 s8a는 오른쪽 눈썹만 찾았고 왼쪽은 오른쪽 모양을 뒤집어 쓴 것이다. 전후 차이가 오른쪽 16.7, 왼쪽 1.7이다. 이런 쪽을 합치면 색이 옅어져, `mirrored`로 표시하고 합친 색에서 뺀다. 시험 영상의 쪽 기록 24개 중 3개다.

### 퍼짐 기준

사진 사이 흔들림이 화장으로 바뀐 양보다 크면 뽑은 색이 화장 색인지 알 수 없다. 그래서 기준을 숫자 하나로 두지 않고 「퍼짐 > 전후 차이」로 뒀다. 시험 영상에서 2건(아이라인 s13b 왼쪽 눈, 덧그리는 눈썹 s23의 합친 색), RBm4rzufBV0에서 1건(아이라인 step_28 뒤집어 쓴 쪽)이 걸렸다.

## 다른 영상 한 편

RBm4rzufBV0(39단계)을 같은 코드로 한 번 돌렸다. 색이 나온 하위 단계 10개(아이섀도 4, 아이라인 4, 립 2), `noArea` 25줄, `colorSpread` 1줄이다. 색 뽑기에 든 시간은 970초 중 15.3초다. 영역을 못 찾는 단계가 많아 색도 그만큼 적다.

## 한계

- **영역이 틀리면 색도 틀린다.** 시험 영상 아이라인 s12 왼쪽 눈은 찾은 칸이 바르기 전보다 밝아진 칸이다(밝기 43 → 61). 오른쪽은 어두워졌다(60 → 48). 아이라인은 색이 바뀐 크기로 찾고 방향은 보지 않아, 눈 뜬 정도나 속눈썹이 달라진 칸이 잡혔다. 색 뽑기에서는 고치지 않았다.
- **넓게 바른 화장은 띠에 닿는다.** RBm4rzufBV0 step_33 오른쪽 눈은 띠 색(68, 16, 13)이 바른 색(68, 17, 14)과 거의 같다. 찾은 영역보다 넓게 바른 섀도가 띠 자리까지 있다.
- **코 쉐딩의 띠는 맨피부로 보기 어렵다.** 어느 간격에서도 띠가 화장 쪽으로 0.4~0.7만큼 같이 움직인다.
- **앞 단계 영역을 그대로 쓴 눈썹**은 이번 단계 지도에서 그 자리의 색을 낸다. 덧그리는 단계라 전후 차이가 작아 `colorSpread`로 빠지기 쉽다.
- 사진이 3장보다 적으면 퍼짐을 재지 못해(`spread` 없음) 퍼짐 기준도 걸리지 않는다.
- 기준값은 시험 영상 한 편의 영역 22개로 골랐다.
