# 바른 곳 찾기 모델 학습 정답지

바른 곳 찾기 모델을 학습시킬 정답지를 합성 화장 사진과 실제 화장 장면으로 만든 기록이다 (S15P31A306-427). 모델 학습은 여기서 하지 않는다. 재료 사진은 [학습 영상과 사진](GUIDE_AREA_TRAIN_FRAMES.md), 실제 장면에 쓴 규칙의 기준값은 [부위별 기준값 자동 탐색](GUIDE_AREA_THRESHOLD_SEARCH.md), 스크립트와 실행 순서는 [ai/tools/guide_area_training/README.md](../../ai/tools/guide_area_training/README.md)에 있다.

## 요약

- 정답지 2,436건을 만들었다. 학습 1,617건, 검증 336건, 시험 483건이다. 자리 일곱 개(립, 블러셔, 눈썹, 아이섀도 윗눈두덩·눈 밑, 아이라인 윗라인·아랫라인)마다 실제 + 합성이 학습 201건, 검증 42건, 시험 60건으로 같다.
- 실제 화장 장면에서 나온 정답지는 5건뿐이다. 학습·검증 영상 8개의 분석하는 단계 69개 가운데, 서비스 규칙이 사진 창을 옮긴 9조합 모두에서 찾은 단계가 립 3개, 블러셔 1개, 아이라인 아랫라인 1개다. 눈썹·아이섀도·아이라인 윗라인은 하나도 없다. 정답지는 사실상 전부 합성이다.
- 사람이 그리거나 고른 정답은 없다. 합성은 칠한 자리가 정답이고, 실제 장면은 규칙이 9조합 모두에서 찾은 칸이 정답이다. 합성의 화장 모양·색·진하기 범위와 섞는 비율은 사람이 정한 생성 설정이고 아래 표에 모두 적었다.
- 합성 화장은 사진 위에 칠한 뒤 서비스와 같은 코드(가림 찾기 모델 포함)로 얼굴 지도에 폈다. 칠한 진하기도 같은 길로 얼굴 지도에 옮겨 `strength.png`로 같이 뒀다.
- 시험 정답지 483건은 시험 영상(GO지승 `VxAXD6PP76I`) 얼굴과 시험 영상에서 잘라 낸 가림 조각으로만 만들었다. 학습·검증에는 시험 영상이 들어가지 않는다.
- 리뷰(MR !212)에서 나온 두 문제를 고쳐 합성을 모두 다시 만들었다. 바탕 사진에 다른 분석 화장을 바르는 장면이 섞이던 것(학습 123·검증 20·시험 71건)과 검증·시험의 화장 값이 학습 같은 순번과 똑같던 것(검증 292·시험 420건)이다. 다시 만든 뒤 둘 다 0건이다. 아래 숫자는 다시 만든 정답지의 것이다.
- 합성 화장 사진은 정답지와 시험에만 쓴다. 사용자 화면에는 쓰지 않는다. 정답지는 저장소에 넣지 않는다.

## 정답지 한 건

`<작업 폴더>/labels/<나눔>/<real 또는 synth>/<이름>/` 폴더 하나가 한 건이고, 같은 자리의 `list.jsonl`이 목록이다.

| 파일 | 내용 |
| --- | --- |
| `before.png`·`after.png` | 단계 직전·직후 얼굴 지도(1024 × 1024 RGB). 모델 입력이다 |
| `label.png` | 칸마다 바른 자리 번호. 0 안 바름, 1 `lip`, 2 `blush`, 3 `brow`, 4 `eyeshadowUpper`, 5 `eyeshadowUnder`, 6 `eyelinerUpper`, 7 `eyelinerUnder`, 255 모름 |
| `strength.png` | 합성에만 있다. 칸마다 칠한 진하기(0~255, 255가 색을 완전히 덮음) |

모름 칸(255)은 학습에서 뺀다. 다음 칸이 모름이다.

| 모름 칸 | 어디서 나오나 |
| --- | --- |
| 얼굴 밖 칸 | 얼굴 지도에서 얼굴 점 조각이 없는 칸 |
| 가려진 칸 | 직전이나 직후에서 모든 사진이 가려진 칸. 서비스 가림 찾기 모델이 찾은 칸과, 합성에서 붙인 조각이 덮은 칸이다 |
| 흐린 가장자리 (합성) | 칠한 진하기가 가장 진한 칸의 10% 이상 50% 미만인 칸 |
| 찾았다 말았다 하는 칸 (실제) | 9조합 가운데 일부만 칠한 칸 |
| 못 믿을 자리 (실제) | 한 조합이라도 못 찾은 자리는 서비스가 그 자리에서 살펴보는 범위를 모두 모름으로 둔다 |

눈을 감은 사진과 부위가 화면 밖인 사진은 서비스 코드(`usable_rows`)가 지도를 만들기 전에 뺀다.

## 실제 화장 장면 정답지

### 규칙

`make_labels.py`는 단계마다 서비스 부위 코드로 바른 곳을 찾되, 판정 도구(`tools/stability_metric.py`)와 같은 방법으로 직전 창을 0·1·2초 앞당기고 직후 창을 0·1·2초 늦춘 9조합마다 다시 찾는다. 창 길이와 계산은 서비스 그대로다.

| 경우 | 처리 |
| --- | --- |
| 9조합이 모두 찾은 자리 | 정답으로 쓴다. 9조합이 모두 칠한 칸이 바른 칸, 일부만 칠한 칸은 모름 |
| 한 조합이라도 못 찾은 자리 | 그 자리의 살펴보는 범위를 모두 모름 |
| 믿을 자리가 하나도 없는 단계 | 정답지로 쓰지 않는다 |
| 눈썹을 못 찾아 앞 단계 영역을 다시 쓰는 단계, 코에만 바른 블러셔, 점막만 그린 아이라인 | 색으로 찾은 것이 아니라 쓰지 않는다 |
| 서비스 창에 쓸 사진이 없는 단계 | 입력 지도를 못 만들어 쓰지 않는다 |

판정 도구의 합격선은 [부위별 기준값 자동 탐색](GUIDE_AREA_THRESHOLD_SEARCH.md)에서 없앴다. 그래서 「판정 도구를 통과한 영역」을 「창을 옮긴 9조합 모두에서 찾은 영역」으로 정했다. 사람이 고른 숫자가 들어가지 않는 가장 엄격한 기준이다.

입력 지도는 옮기지 않은 조합(서비스 창)의 사진으로 서비스와 같이 만든다(얼굴 크기 맞추기 → 흐린 사진 빼기 → 가린 칸을 빼고 칸마다 가운데 값). 같은 단계에서 다른 부위는 바르지 않았다고 보고 0으로 둔다.

### 읽는 법

- 규칙의 기준값은 시험 영상 하나로 골랐다. 다른 영상 8개에서는 바른 단계의 대부분을 못 찾거나 창에 따라 찾았다 말았다 한다. 9조합 가운데 한 번도 못 찾은 단계가 30개, 서비스 창에 쓸 사진이 없는 단계가 18개다.
- 그래서 실제 장면은 학습 3건·검증 2건이고, 눈썹·아이섀도·아이라인 윗라인은 실제 정답이 없다. 모델이 실제 화장 모습을 실제 정답으로 배우는 양은 거의 없다.
- 기준을 낮추면(예: 9조합 중 과반) 건수는 늘지만 창에 따라 뒤집히는 영역이 정답에 들어간다. 여기서는 낮추지 않았다. 단계마다 조합 수는 `labels/real_steps.json`에 남겼으므로 기준을 바꿔 다시 고를 수 있다.

## 합성 정답지

### 만드는 차례

| 차례 | 하는 일 | 코드 |
| --- | --- | --- |
| 바탕 | 그 부위의 첫 단계가 시작하기 전에 끝나고 다른 분석하는 화장(립·블러셔·눈썹·아이섀도·아이라인) 단계 시간과 겹치지 않는 묶음(단계 앞뒤 5초)에서 부위가 다 보이는 사진을 고른다. 시각 순서로 앞 반은 직전, 뒤 반은 직후이고 한쪽 8장까지 고르게 뽑는다. 사진이 모자라면 다음 묶음으로 넘어간다(6번까지) | `plan.bare_ranges`·`halves`·`spread`, `make_synth.bare_rows` |
| 칠하기 | 화장 모양을 얼굴 지도 위 진하기 지도로 만들고, 직후 사진마다 얼굴 점 조각(삼각형)을 따라 사진 자리로 옮겨 색을 올린다. 칠할 자리의 밝기만큼 화장 색도 밝히거나 어둡혀 피부 결이 남는다 | `paint.make`·`to_photo`·`tint` |
| 조명 | 직후 사진 전체의 밝기와 색 기운을 바꾼다 | `paint.relight` |
| 가림 | 직전·직후 사진 몇 장에 가림 조각을 그 부위 근처에 붙인다 | `make_synth.occlude` |
| 얼굴 지도 | 서비스와 같은 코드로 흐린 사진을 빼고, 가림 찾기 모델이 찾은 칸을 빼고 칸마다 가운데 값을 낸다 | `drop_blurry`·`rows_to_known_map` |
| 정답 | 사진에 올린 진하기를 같은 길로 얼굴 지도에 펴서 사진들의 가운데 값을 낸다. 가장 진한 칸의 50% 이상이 바른 칸, 10~50%는 모름 | `labels.strength_cells`·`label_map` |

앞 반·뒤 반으로 나눈 것은 직전과 직후 사이의 고개·표정 차이가 실제 영상 그대로 들어가게 하려는 것이다. 사진 위에 칠한 뒤 펴므로 펴면서 생기는 번짐과 고개 방향의 영향도 실제 화장 장면과 같은 길을 지난다.

### 화장 모양

| 자리 | 모양 | 색 | 진하기(가장 진한 칸) |
| --- | --- | --- | --- |
| `lip` | 붉은·누드·브라운. 입술 전체, 셋에 하나는 입 가운데에서 멀수록 옅은 그러데이션 | 모양마다 3색 | 0.3~0.9 |
| `blush` | 높은(볼 가운데에서 위로)·낮은(아래로)·좁은(반지름 작게). 둥글게 번진 모양을 두 볼에 좌우 뒤집어 | 4색 | 0.15~0.6 |
| `brow` | 일자(곧은 띠)·갈매기(꼬리 쪽 3분의 2가 솟은 띠)·덧그림(원래 눈썹을 3~7칸 넓힘) | 4색 | 0.3~0.8 |
| `eyeshadowUpper` | 윗눈두덩. 눈 테두리에서 18~46칸까지 멀수록 옅게 | 5색 | 0.2~0.8 |
| `eyeshadowUnder` | 눈 밑(12~30칸)·흰색 애교살·회색 애교살(8~18칸) | 5색, 흰색 2색, 회색 2색 | 0.2~0.8 |
| `eyelinerUpper` | 윗라인(두께 3~7칸, 넷에 셋은 꼬리)·꼬리만·가는 선(1.5~3칸). 꼬리는 15~42칸, 10~35도 | 검정 2색·진갈색 2색 | 0.6~1.0 |
| `eyelinerUnder` | 아랫라인(두께 3~7칸, 반은 눈꼬리 쪽 절반만) | 검정 2색·진갈색 2색 | 0.6~1.0 |

색은 고른 색에서 채널마다 ±12를 더한다. 모양은 얼굴 지도에서 그리므로 사람마다 눈·입 크기에 맞게 늘어난다.

### 섞는 것

| 설정 | 값 | 내용 |
| --- | --- | --- |
| 안 바른 쌍 | 자리마다 칠한 수의 15% | 아무것도 칠하지 않는다. 정답은 모두 0이고 조명·가림은 똑같이 섞는다 |
| 조명 변화 | 50% | 직후 사진의 밝기 0.9~1.1배, 색 기운은 채널마다 0.97~1.03배 |
| 가림 | 40% | 직전·직후 각각 사진 1~4장에 조각 하나씩 |

### 리뷰로 바꾼 것 (MR !212)

처음 만든 합성 정답지에 문제가 두 개 있어 고치고 합성 세 나눔을 모두 다시 만들었다. 실제 장면 정답지 5건은 이웃 단계 사진을 빼고(`within_step`) 만들어서 그대로다.

| 무엇 | 전에는 | 이제 | 이유 |
| --- | --- | --- | --- |
| 바탕 묶음 | 그 부위를 바르기 전에 끝나는 묶음이면 모두 씀 | 다른 분석하는 화장 단계 시간과 겹치는 묶음은 뺌(`plan.bare_ranges`) | 묶음은 대부분 이웃 단계 시간 안에 있다. 이웃 단계가 다른 분석 화장이면 앞 반과 뒤 반 사이에 그 화장이 실제로 늘어나는데, 합성 정답은 칠한 자리 말고 모두 안 바름이다. 직전·직후 사진 사이에 다른 분석 화장 단계가 걸친 합성이 학습 1,614건 중 123건, 검증 334건 중 20건, 시험 483건 중 71건이었다 |
| 난수 씨앗 | `[427, 나눔을 돈 차례, 자리, 순번]`. 나눔을 `--only`로 따로 돌려 나눔 차례가 셋 다 0 | `[427, workspace.SPLITS 순서(학습 0·검증 1·시험 2), 자리, 순번]`(`make_synth.job_seed`) | 이름이 같은 건 가운데 검증 292건, 시험 420건 전부가 학습과 화장 모양·색·진하기·조명이 같았다. 시험에 나올 화장을 학습에서 미리 보게 된다. 학습 씨앗은 전과 같다 |

다른 분석 화장과 겹치는 묶음을 다루는 방법으로 둘을 견줬다.

| 후보 | 결과 | 받았나 |
| --- | --- | --- |

## 품질 그림

`label_report.py`가 나눔·출처·자리마다 8건을 고르게 뽑아 직전 지도·직후 지도·정답 겹침을 나란히 둔 그림을 `<작업 폴더>/labels/report/<나눔>_<출처>_<자리>.jpg`로 남긴다. 바른 칸은 자리 색 테두리, 모름 칸은 회색 줄무늬다. 그림은 사람이 보고 합격·불합격을 정하는 데 쓰지 않고 기록으로 남긴다.

## 남은 것

- 실제 장면 정답이 5건이라, 모델이 실제 화장을 얼마나 맞히는지는 이 정답지로 잴 수 없다. 모델 비교·채택은 시험 영상의 데이터 지표로 한다.
- 시험 영상에서 그 부위를 바르기 전이고 다른 분석 화장과 겹치지 않는 묶음은 립 28개, 블러셔 23개, 아이라인 7개, 아이섀도 3개, 눈썹 1개다. 눈썹을 가장 먼저 그리는 영상이라서다. 시험 세트의 눈썹 정답지 69건은 묶음 하나의 사진에, 아이섀도 138건은 묶음 3개의 사진에 화장만 바꿔 만든 것이다.
- 합성 화장은 한 번에 한 자리만 칠한다. 한 단계에서 두 자리를 같이 바르는 경우(윗눈두덩과 눈 밑)는 합성에 없다.
- 실제 장면의 「안 바른 시간」 쌍은 넣지 않았다. 안 바른 쌍은 합성에만 있다.
