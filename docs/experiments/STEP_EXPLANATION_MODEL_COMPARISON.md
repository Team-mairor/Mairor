# 단계 설명 모델 비교

2026-10-27 · S15P31A306-249

단계 설명을 만들 모델을 고르려고 같은 입력을 GMS로 세 모델에 보내 비교했다.

## 요약

| | GPT `gpt-5.4-mini` | Gemini `gemini-3.5-flash-lite` | Claude `claude-haiku-5-5` |
|---|---|---|---|
| 검토에서 찾은 문제 | 6건 | 11건 | **3건** |
| 그중 입력 내용 누락 | 4건 | 4건 | **0건** |

**잠정 추천: Claude Haiku 5.5.** 입력 내용을 빠뜨리지 않았고 문제가 가장 적다. 눈 단계(10~14)를 모델마다 3번 돌려도 같은 경향이었다([눈 단계 반복 실행](#눈-단계-반복-실행)). 비용과 응답 시간은 [비용과 속도](#비용과-속도)에서 보듯 걸림돌이 아니다. 영상 1편으로 본 결과라 [남은 작업](#남은-작업)을 마친 뒤 확정한다.

## 시험 조건

- 입력: `ai/samples/local_01/guide_input.json` (19단계). 글만 보내고 이미지는 보내지 않았다
- 세 모델 모두 같은 프롬프트(`ai/tools/explain_prompt.txt` v2), 같은 응답 형식, 기본 설정으로 단계마다 한 번씩 불렀다
- 생각 수준(effort)은 보내지 않았다. Claude Haiku 5.5는 생략하면 `medium`과 같다 ([Effort 문서](https://platform.claude.com/docs/en/build-with-claude/effort))
- 결과 형식

| 칸 | 규칙 |
|---|---|
| 동작 | 1~4개, 하는 순서대로, 25자 이내 |
| 팁 | 관련 동작에 붙인다. 단계당 2개, 30자 이내, 요령·주의 |
| 넘어갈 때 | 입력에 있을 때만 |
| 공통 | 해요체. 제품·도구 이름은 쓰지 않는다. 입력에 없는 내용(당연해 보이는 준비 동작 포함)은 쓰지 않는다 |

- 평가: 19단계를 모두 읽고 누락·지어냄·뜻 바뀜·깨진 문장을 표시했다. 코드 검사(글자 수·개수·근거 번호·숫자·제품 이름·도구·방향·말투)도 함께 돌렸다

## 결과

### 검토 결과

괄호 안은 단계 번호다.

| 문제 | GPT | Gemini flash-lite | Claude |
|---|---|---|---|
| 입력 내용 누락 | 4 (1·3·4·12) | 4 (1·3·5·12) | 0 |
| 입력에 없는 내용을 지어냄 | 0 | 3 (16 두 건·17) | 1 (16) |
| 뜻이 바뀜, 쓰지 말라고 한 일반 상식 | 1 (1) | 0 | 2 (3·18) |
| 깨진 문장, 쓸모없는 팁 | 0 | 2 (19) | 0 |
| 동작과 같은 말을 팁에서 되풀이 | 1 (11) | 2 (4·11) | 0 |
| **합계** | **6** | **11** | **3** |

- **GPT**: 입력을 줄여서 옮긴다. 지어내지는 않지만 시간(5~10분)·횟수(두 번)·숫자(0.1mm)·두 번째 도구(퍼프)를 빠뜨린다.
- **Gemini flash-lite**: 빠뜨리기도 하고 지어내기도 한다. 깨진 문장("발라워요")이 나왔다.
- **Claude**: 입력을 가장 잘 살린다. 대신 넘치는 쪽으로 틀린다. 입력에 없는 준비 동작(16), 일반 상식 팁(3), 제품 효과를 동작으로 바꾼 문장(18)이 나왔다.

### 단계별 예시

**4단계 선 앰플: 누락**

```
입력  얼굴에 얇게 코팅하듯이 바르고 퍼프로 두드려 흡수시켜줍니다.
      팁: 모공 사이사이에 넣어준다는 느낌 / 잘 뭉치는 코 옆과 눈두덩이, 눈 밑에 꼼꼼하게

GPT     1 얼굴에 얇게 발라요  (요령: 코팅하듯 발라요)
        2 모공 사이사이에 발라요
        3 코 옆과 눈두덩이, 눈 밑에 꼼꼼히 발라요                ← 퍼프로 두드리기가 빠짐
Gemini  1 얼굴에 얇게 코팅하듯이 발라요  (요령: 모공 사이사이에 넣어준다는 느낌으로 발라요)
        2 퍼프로 두드려 흡수시켜요
        3 코 옆과 눈두덩이, 눈 밑에 꼼꼼하게 발라요  (주의: 잘 뭉치는 부위이므로 꼼꼼히 발라요)  ← 같은 말 되풀이
Claude  1 얼굴에 얇게 코팅하듯 발라요  (요령: 모공 사이사이에 넣는 느낌으로요)
        2 코 옆과 눈두덩이, 눈 밑을 꼼꼼히 발라요  (요령: 잘 뭉치는 부위예요)
        3 퍼프로 두드려 흡수시켜요
```

**16단계 하이라이터: 입력에 없는 준비 동작**

```
입력  하이라이터 색상을 코끝, 콧대, 눈 앞머리에 발라줍니다.  (도구: 손가락)

GPT     1 코끝에 발라요  2 콧대에 발라요  3 눈 앞머리에 발라요
Gemini  1 손가락에 묻혀요  (요령: 코끝과 콧대에 소량만 발라요)   ← "묻혀요", "소량"은 입력에 없음
        2 코끝과 콧대, 눈 앞머리에 발라요
Claude  1 하이라이터를 손가락으로 찍어요                         ← "찍어요"는 입력에 없음
        2 코끝, 콧대, 눈 앞머리에 발라요
```

**1단계 스킨케어 패드: 뜻이 바뀜**

```
입력  팁: 머리 말리는 동안 5분에서 10분 정도 붙이고 있으면 ... 수분을 채워줍니다.
      주의: 피부가 얇아서 살짝만 만져도 빨개지니 너무 신경 쓰지 않아도 됩니다.   ← 크리에이터 본인 얘기

GPT     3 피부가 빨개져도 너무 신경 쓰지 않아요                  ← 본인 얘기를 따라 할 동작으로 바꿈
Claude  3 5~10분 정도 그대로 두어요                              ← 시간을 살림
```

### 눈 단계 반복 실행

눈 단계 5개(10 베이스 섀도우, 11 언더 아이라인, 12 점막 아이라인, 13 애교살, 14 마스카라)를 모델마다 3번씩 돌렸다.

| | GPT | Gemini flash-lite | Claude |
|---|---|---|---|
| 12단계 "0.1mm"를 살림 | 0/3 | 1/3 | **3/3** |
| 11·12단계 팁에 이유를 씀 ("띄우면 → 커 보여요") | 0/6 | 0/6 | **6/6** |
| 11단계에서 동작과 같은 말을 되풀이 (주의·넘어갈 때) | 3/3 | 3/3 | **1/3** |
| 글자 수 초과 | 0 | 2 | 0 |
| 입력에 없는 말 | 0 | 0 | 1 (13단계 "자연스러워요") |
| 3번 모두 같은 문장인 단계 (5개 중) | **2** | 0 | 0 |

**12단계 점막 아이라인** (입력: 점막에서 살짝 0.1mm 띄워 그림, 띄우면 눈이 더 커 보임, 뒷트임 부분은 조금 더)

```
GPT     #1·#2·#3  1 점막에서 살짝 띄워 그려요  (요령: 눈이 더 커 보여요)      ← 3번 같음, 0.1mm 빠짐
                  2 뒷트임 부분은 조금 더 잡아줘요
Gemini  #1        1 점막에서 살짝 띄워 그려요  (요령: 눈이 더 커 보여요)
        #2        1 점막에서 살짝 0.1mm 띄워 아이라인을 그려요  (요령: 눈이 더 커 보여요)  ← 26자, 글자 수 초과
        #3        1 눈 점막에서 살짝 띄워 그려요  (요령: 눈이 더 커 보여요)
Claude  #1        1 점막에서 살짝 0.1mm 띄워 그려요  (요령: 띄우면 눈이 더 커 보여요)
        #2        1 눈 점막에서 살짝 0.1mm 띄워 그려요  (요령: 점막에서 띄우면 눈이 더 커 보여요)
        #3        1 눈 점막에서 0.1mm 띄워 선을 그려요  (요령: 점막에서 띄우면 눈이 더 커 보여요)
```

**11단계 언더 아이라인: 같은 말 되풀이** (3번째 실행)

```
GPT     2 경계를 부드럽게 퍼뜨려요     (주의: 경계가 똑 떨어지지 않게 해요)       ← 같은 말
Gemini  2 경계가 똑 떨어지지 않게 퍼뜨려요  (주의: 너무 똑 떨어지지 않게 퍼뜨려요)  ← 같은 말
Claude  2 경계가 똑 떨어지지 않게 퍼뜨려요   (넘어갈 때: 경계가 똑 떨어지지 않게 퍼지면 끝나요)  ← 같은 말
```

GPT·Gemini는 3번 모두 주의로 되풀이했다. Claude는 주의는 붙이지 않았고, 3번 중 이 한 번만 넘어갈 때에 같은 말을 썼다.

- **GPT**: 가장 안정적이다(12·14단계는 3번 모두 같음). 대신 숫자를 늘 빼고, 팁이 "눈이 더 커 보여요"처럼 결과만 있어 무엇을 하면 그런지가 빠진다.
- **Gemini flash-lite**: 실행마다 0.1mm를 넣기도 빼기도 하고, 넣으면 글자 수를 넘긴다.
- **Claude**: 문장은 실행마다 바뀌지만 내용(0.1mm, 이유 있는 팁)은 3번 모두 같다. 문장 끝 마침표가 실행마다 붙었다 빠졌다 해서 화면에 띄우기 전에 코드로 정리해야 한다.

### 형식 준수

| | GPT | Gemini flash-lite | Claude |

| 형식대로 답한 단계 | 19/19 | 19/19 | 19/19 |

## 비용과 속도

GMS 사용량 = 공개 요금(달러) × 10,000이고, 사이트 숫자와 같은 단위다. 생각(thinking) 토큰도 출력 요금으로 계산된다.

| 모델 | 공개 요금 (100만 토큰당 입력 / 출력) | 입력 토큰 | 출력 토큰 | 생각 토큰 | 영상 1편 | 단계당 | 단계당 응답 시간 (평균 / 최대) |
|---|---|---|---|---|---|---|---|
| GPT | $0.75 / $4.50 | 17,073 | 2,098 | 0 | 222 | 11.7 | 1.7초 / 2.5초 |
| Gemini flash-lite | $0.30 / $2.50 | 13,075 | 2,136 | 0 | **93** | 4.9 | **1.3초 / 2.0초** |
| Claude | $0.10 / $0.50 | 38,440 | 3,109 | 14,524 | 127 | 6.7 | 5.8초 / 10.7초 |

- Claude는 flash-lite의 약 1.4배로, 영상 1편에 127(약 $0.013)이다. 비용의 약 57%가 생각 토큰이라, 생각 수준을 낮추면 더 줄일 수 있다.
- Claude가 가장 느리지만 가이드 생성은 콜백 방식(S15P31A306-250)이다. 단계를 동시에 부르면 영상 1편이 수십 초 안에 끝난다.
- GPT는 첫 사용 때 사이트 숫자가 공개 요금 계산의 약 1.75배였다(404 vs 231). 원인을 확인하기 전까지는 영상 1편에 약 390으로 본다.
- `gemini-3.5-flash`는 영상 1편에 1,844였다. flash-lite의 약 20배이고 대부분 생각 토큰이라 flash-lite로 바꿨다.

## 공통 한계

- 입력이 짧은 단계는 세 모델 모두 한 줄이다(8단계 "얼굴에 발라요"). BE가 뽑는 내용을 늘려야 풀린다. BE와 정할 일이다.
- 스킨케어 1~4단계는 명세(ANALYSIS-001)상 제외 단계인데, 입력에 제외 표시가 없어 설명을 만들고 있다. BE와 정할 일이다.
- 뜻 바뀜·일반 상식·깨진 단어는 코드 검사로 못 잡는다(S15P31A306-252).

## 남은 작업

1. 영상 2~3편을 더 돌린다. 베이스·아이·블러셔·립이 고르게 들어간 영상으로 한다.
2. 눈 단계 밖의 단계도 3번씩 돌려 실행마다 결과가 얼마나 달라지는지 본다.
3. Claude의 생각 수준을 낮춰 비용·시간·품질을 비교한다.
4. 오픈소스 모델 후보를 비교한다(티켓 249 범위).
5. GMS의 GPT 단가를 확인한다.

## 재현 방법

`ai/` 폴더에서 실행한다. `.env`에 `GMS_API_KEY`가 있어야 한다.

```bash
uv run python tools/explain_compare.py              # 결과 → tools/explain_runs/<영상 ID>_<회차>.json
uv run python tools/explain_compare.py --steps 10-14  # 눈 단계만
uv run streamlit run tools/explain_viewer.py        # 결과 보기
```

이 문서의 숫자는 `ai/tools/explain_runs/`의 `eFzG30avtOI_2.json`(19단계)과 `eFzG30avtOI_2~4.json`의 눈 단계(반복 실행)에서 나왔다.
