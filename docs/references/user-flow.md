# 최종 유저플로우 (v11)

<callout icon="🧭" color="gray_bg">
프로토타입 v11(최종 유저플로우v11) 기준으로 정리한 최종 사용자 흐름. 기존 유저플로우를 대체하며, 화면별 상세·예외 상태는 아래 각 단계에 이어서 기록한다. 이 파일이 원본이다.
</callout>

## 전체 흐름 한눈에 보기

이 문서는 목표 화면 흐름이다. 각 화면의 API 구현·머지·배포 완료 상태는 [BE 구현 현황](../../backend/docs/implementation-status.md)에서 별도로 확인한다. 현재 얼굴 등록 CRUD는 구현되어 있고 실행·단계 사진·완료·리포트 전체 흐름은 후속 작업이다. 얼굴 자동 촬영과 조건 안내는 FE, 사진 파일·동의·소유권 검증과 저장은 BE 책임이다.

인트로 → 로그인/회원가입 → (최초 1회) 온보딩·파우치 담기 → 홈 → 영상 입력 → 분석 로딩(얼굴 등록 · 파우치 확인) → 미리보기 → 제품 체크 ↔ 입혀보며 고르기 → 튜토리얼 안내·사진 저장 동의 → 튜토리얼 → 완성 → 리포트

- 예외 진입: 홈 '다시 따라 하기' · 검수된 가이드 '바로 따라 하기' → 분석 로딩 없이 준비 단계부터
- 상시 접근: 마이페이지(내 파우치 · 리포트)

### 공통 내비게이션

- <b>하단 탭 5개</b>: 홈 · 촬영(→ 네컷 사진) · 튜토리얼(→ 영상 입력) · 파우치(→ 마이페이지 내 파우치) · 리포트(→ 마이페이지 리포트)
- 표시 화면: 홈 · 촬영 · 영상 입력 · 마이페이지 · 리포트 상세(뒤로·홈 버튼 없음). 제품 등록 시트가 열리면 숨기고, 로딩\~완성에서는 표시하지 않음
- 마이페이지 상단: 프로필(MY BEAUTY ARCHIVE · 'OO의 파우치와 룩') + 내 파우치 · 리포트 탭(개수 표시)

---

## 0. 인트로

- <b>진입</b>: 앱 실행 시
- <b>화면</b>: 로고 모션 → 얼굴 위에 부위 라벨이 차례로 뜨는 연출(BLUSH · CORAL / LIP · ROSE MLBB / BLUSH · PEACH). 수치(%)는 표시하지 않음
- <b>다음</b>: 약 6초 후 자동 이동, 또는 건너뛰기
  - 로그인 유지 중 → 홈 / 로그인 없음 → 로그인 / 세션 만료 → 로그인 + 만료 안내
- <b>관련</b>: USERS-003

## 1. 로그인 · 회원가입

### 1-1. 로그인

- <b>화면</b>: 이메일·비밀번호 로그인 · Google 로그인 · 비밀번호 재설정 · 회원가입 이동. 빈 값이면 로그인 버튼 비활성, 처리 중 상태 표시
- <b>성공</b>: 이 기기에서 온보딩을 본 적 없으면 → 온보딩 / 본 적 있으면 → 홈
- <b>예외</b>
  - 실패: '이메일 또는 비밀번호를 확인해 주세요'(가입 여부를 구분하지 않음)
  - 반복 실패: 'N초 후에 다시 시도해 주세요' + 카운트다운 (프로토타입: 3회 · 30초)
  - 세션 만료: '로그인이 만료됐어요. 다시 로그인해 주세요' / 튜토리얼 중 만료: '진행 중이던 메이크업은 기록 없이 종료됐어요'
  - Google: 계정 선택 → 성공 / 취소 '로그인을 취소했어요' / 실패 '다시 시도' / 같은 이메일의 자체 계정이 있으면 '자동으로 연결되지 않아요 · 이메일로 로그인'
- <b>게스트(둘러보기)</b>: 제공하지 않음 — 모든 기능은 로그인 후 사용
- <b>관련</b>: USERS-002 · USERS-003 · USERS-004

### 1-2. 비밀번호 재설정

1. 가입한 이메일 입력 → 인증 코드 발송(가입 여부와 관계없이 같은 안내)
2. 메일로 받은 6자리 코드 입력 (10분 유효 · 60초 후 재발송 · 재발송 시 이전 코드 무효)
3. 새 비밀번호 입력(가입과 같은 규칙) → 로그인 화면 + 완료 안내. 기존 세션은 모두 종료, 자동 로그인 없음

- Google로만 가입한 계정은 코드 대신 'Google로 로그인' 안내

### 1-3. 회원가입

- <b>입력</b>: 이메일 + <b>중복 확인 버튼</b>(비밀번호까지 입력하기 전에 확인) · 비밀번호 · 비밀번호 확인
- <b>비밀번호 규칙</b>: 8\~64자 · 영문 · 숫자 · 특수문자 (조건별 실시간 체크)
- <b>약관</b>: 이용약관 · 개인정보 처리방침 필수 동의(전체 동의 제공)
- <b>화면</b>: 조건을 모두 만족해야 '가입하기' 활성 → 가입 중 → 완료 시 로그인 화면으로 이동(가입 완료 안내 + 이메일 자동 입력) → 로그인하면 온보딩. 비밀번호는 72바이트 이하(한글은 영문보다 길게 계산), 초과 시 '비밀번호가 너무 길어요'
- <b>관련</b>: USERS-001

## 2. 온보딩 · 파우치 담기

- <b>진입</b>: 이 기기에서 처음 로그인했을 때 1회. 강제 아님
- <b>기능 소개 3장</b> (자동 넘김 · '다음'은 다음 장 · '건너뛰기'는 소개를 넘기고 파우치 담기로)
  1. 내 얼굴에 맞춰 영역을 그려요 — 얼굴을 실시간으로 따라가며 영상 속 메이크업 영역을 점선으로 표시
  2. 진하기를 실시간으로 비교해요 — 레퍼런스 대비 진하기 게이지(레퍼런스 위치선만, 판정 구간 없음)
  3. 단계별 기록 — 사진 저장에 동의하면 스텝마다 얼굴을 남기고, 모든 스텝을 마치면 리포트 생성
- <b>파우치 담기</b>: 가진 제품 등록(등록 시트는 11장과 동일) → '시작하기' / '나중에 할게요' → 홈. 완료 시 기기에 기억해 다시 뜨지 않음
- <b>관련</b>: POUCH-001 · GUIDE-002 · GUIDE-013

## 3. 홈

- <b>구성</b>
  - 새 메이크업 영상 추가(YouTube 검색) → 영상 입력
  - <b>다시 따라 하기</b>: 최근 리포트의 지난 가이드 + '다시 하기' → 분석 없이 준비 단계(얼굴 등록 → 파우치 확인) → 입혀보기. 이어 하기가 아닌 새 실행, 매칭은 현재 파우치 기준으로 다시 계산
  - <b>분석한 가이드</b> 카드: 분석이 끝난 영상. 운영자 검수 없이 바로 'READY · 따라 하기' → 바로 따라 하기 준비(11.12 팀 합의, S15P31A306-409). 'IN REVIEW · 검수 중'은 자동 공개 전에 끝난 옛 작업에만 나온다(운영 DB의 옛 검수 대기는 11.12에 정리해 지금은 없다). 알림(푸시)은 없음
  - 파우치 보드(스티커 최대 5개 · 탭하면 수정 · '제품 추가' → 내 파우치 + 등록 시트) · 최근 리포트
- <b>첫 이용(빈 상태)</b>: 리포트·파우치가 없으면 '첫 메이크업을 시작해 보세요' · 파우치 등록 안내
- <b>관련</b>: REPORT-002 · POUCH-004 · VIDEO-001 · ANALYSIS-006

## 4. 영상 입력

- <b>입력 방식</b>: YouTube 검색 + 추천 Top 4 (릴스 링크·기기 영상 업로드는 제외)
- <b>영상 고르기</b>: 선택 시 썸네일 · 제목 · 길이 · 챕터 표시, 'YouTube에서 보기' 링크(서비스 안 재생 없음) → CTA
- <b>영상 상태별 분기</b>
  - 검수된 가이드 있음 → '바로 따라 하기'(분석 없이 준비 단계로)
  - 다른 사람이 분석 중 → 진행 중인 분석에 합류(로딩이 중간부터)
  - 새 영상 → 신규 분석 시작(Top 4도 탭하면 바로 분석)
  - 분석 불가 영상(비공개·삭제·연령 제한 등) → 선택 불가 안내
- <b>예외</b>
  - 검색 결과 없음 / 조회 실패 구분 → 다시 시도
  - 일일 신규 분석 한도 초과(429) → '오늘 새로 분석할 수 있는 횟수를 다 썼어요 · 가이드 있음 영상은 바로 따라 할 수 있어요'
  - 내 가이드 목록(최근 순 · 완주한 가이드 · 이어서 하기) 제공 — '이어서 하기'는 중도 종료 시 기록이 남지 않는 정책(GUIDE-011)과 충돌 → '남은 확인 필요' 참고
- <b>관련</b>: VIDEO-001 · VIDEO-002 · VIDEO-005

## 5. 분석 로딩 · 준비 (얼굴 등록 · 파우치 확인)

- <b>진행 단계</b>(API progressStage): 대기 → 영상 불러오기 → 구간 나누기 → 제품 인식 → 단계 추출 → 가이드 구성. % · 남은 시간 표시
- <b>Found in video</b>: 찾은 제품이 하나씩 나타남. 보유 여부는 파우치 기준(색으로 구분), 없는 제품을 탭하면 제품 등록 시트
- <b>기다리는 동안 — 얼굴 등록 모달</b>
  - 실시간 조건 체크: 밝고 고른 조명 · 적정 거리 · 정면 · 가림 없음(필수 4개) + 맨얼굴(권장, 메이크업이 감지돼도 진행)
  - 조건 충족 시 정면 1장 자동 촬영 → 저장. 용도: 이번 메이크업의 조명·색온도(환경) 기준, 실행마다 새로 등록 · 다른 실행에 재사용 없음
  - '다시 촬영' · '나중에'
- <b>파우치 확인 모달</b>: '기다리는 동안 내 파우치를 확인해 볼까요?' → 제품 등록 / '변경 없어요' · '다 했어요'
- <b>이용 준비 두 줄</b>: 가이드 준비(분석 중 N% · 검수 대기 · 완료) + 얼굴 인식 준비(등록 필요 · 완료). 둘 다 완료돼야 '미리보기 보기', 얼굴 미등록이면 '얼굴 등록하고 미리보기'
- <b>예외</b>
  - 분석 실패 · 시간 초과: 멈춘 단계 표시. retryable이면 '다시 시도'(멈춘 단계부터) + '다른 영상 고르기', 불가면 '다른 영상 고르기'
  - 검수 대기: '분석은 끝났고, 검수 중이에요' → 홈으로(홈 '검수 중 가이드' 카드에서 상태 확인)
  - 검수 반려: '이 영상은 가이드로 쓸 수 없어요' → 다른 영상 고르기
- <b>바로·다시 따라 하기 진입 시</b>: 로딩 없이 'READY · 다시/바로 따라 하기 준비'에서 얼굴 등록 → 파우치 모달 → 입혀보기
- <b>관련</b>: VIDEO-003 · VIDEO-004 · ANALYSIS-006 · CAMERA-005(제안) · POUCH-002

## 6. 미리보기 (실시간 입혀보기)

- <b>화면</b>: 실시간 카메라에 영상 속 메이크업을 입혀 봄. '메이크업 입히기' / '민낯으로 보기' 전환
- <b>적용 범위</b>: 색 있는 단계만(아이섀도 · 아이라이너 · 블러셔 · 하이라이터 · 립). 피부 표현(파운데이션·컨실러)은 제외 — 'N / 전체 단계 미리보기' 안내. '나에게 맞춤'(퍼스널 컬러 보정)은 제외 기능
- <b>카메라 오류 안내</b>: 권한 거부 · 카메라 없음 · 다른 앱 사용 중 · 얼굴 인식 로드 실패 + '다시 시도'. (프로토타입은 샘플 얼굴로 대체)
- <b>진행 중 인식 알림</b>: 얼굴 이탈 · 고개 돌림 · 손·도구 가림 · 너무 멀어요 · 조명 변화(등록 이미지 대비) → 메이크업 숨김, 회복 시 다시 표시
- <b>다음</b>: '이 메이크업으로 시작하기' → 제품 체크 / 뒤로 → 영상 입력
- <b>관련</b>: PREVIEW-001 · CAMERA-001 · CAMERA-004

## 7. 제품 체크 ↔ 입혀보며 고르기

하나의 화면을 두 보기로 제공한다. 선택값은 공유되고, 오른쪽 위 버튼('≡ 목록 보기' / '☺ 얼굴에 입혀보기')으로 언제든 전환. 보던 부위가 유지되고 목록으로 돌아오면 해당 줄이 강조된다.

### 7-1. 목록

- 'N / 전체 · 내 파우치와 맞춰봤어요' + 보유 · 대체 · 없음 탭
- 각 줄: 영상 속 제품 → 내가 쓸 제품. 영상 속 제품 인식 상태 라벨: '추정' · '설명란에만 있음' · '이름만 확인'(확정 제품은 라벨 없음)
- '없음'은 사유 구분 없이 '없음'으로만 표시
- <b>바꾸기 패널</b>: 내 파우치에서 같은 카테고리이며 대표 색상이 있는 제품 전체를 직접 고를 수 있다. 색이 가까운 상위 3개는 '추천 1·2·3'(유사도 % 노출 없음)으로 표시한다. 다른 카테고리·대표 색상이 없는 제품은 선택할 수 없다. '이 제품 없이 진행' · '지금 선택 유지'
- 빈 파우치: 전 단계 '없음' + '제품을 등록하면 다시 맞춰 봐요' · 제품 등록

### 7-2. 입혀보며 고르기

- 부위 칩(아이섀도 · 아이라이너 · 블러셔 · 하이라이터 · 립)별로 후보를 골라 얼굴에 바로 입혀 봄. 후보: 추천 1·2·3 · 같은 종류 · '없이 진행' · '전체 보기'(바꾸기 패널)
- '누르고 있으면 영상과 비교' — 누르는 동안만 영상 메이크업으로 보여 줌
- '색은 영상에서 추정한 값이라 실제 발색과 다를 수 있어요'
- 버튼: ← · '다음 · 부위' · '이 조합으로 시작'(항상)

### 7-3. 시작 확인

- 없는 제품이 있으면 '없는 제품 N개는 건너뛰고 시작할까요?', 없으면 '이대로 시작할까요?' + '시작하면 제품을 바꿀 수 없어요'
- 매칭 만료(409): 매칭 재조회 + '파우치가 바뀌어 다시 맞춰 봤어요'(프론트 처리)
- <b>관련</b>: RECOMMEND-001/002 · GUIDE-001 · GUIDE-004 · ANALYSIS-002/003/004 · PREVIEW-001

## 8. 튜토리얼 안내 · 사진 저장 동의

- <b>안내 3장</b>: 온보딩과 같은 내용. 이 기기에서 튜토리얼을 처음 시작할 때만 표시. '다음' → 3장 '시작하기', '건너뛰기'는 동의 카드로
- <b>단계 사진 저장 동의(매번, 필수)</b>: '단계 사진 저장에 동의해 주세요'
  - 저장 항목: 스텝별 얼굴 사진(최대 N장) / 쓰는 곳: 내 리포트의 과정 사진 / 삭제: 리포트를 지우면 함께 삭제
  - '돌아가기'(제품 확인으로) / '동의하고 시작'. 동의해야 튜토리얼을 시작할 수 있음
  - 얼굴 등록 사진(환경 기준)은 별개
- <b>튜토리얼 중 '안내 다시 보기'</b>: 슬라이드만 보고 '튜토리얼로 돌아가기'(동의는 다시 묻지 않음)
- <b>관련</b>: GUIDE-002 · API-GUIDE-003

## 9. 튜토리얼

- <b>화면</b>: 실시간 카메라 + 현재 단계의 바를 영역을 얼굴에 맞춘 점선으로 표시(베이스 얼굴 윤곽 · 컨실러 눈 밑 · 섀도 눈두덩 · 라인 속눈썹 라인 · 블러셔 광대 · 하이라이트 콧대 · 립 입술)
- <b>상단</b>: '나가기' + 부위 묶음 진행 바 'N / 전체'(연속한 같은 부위 단계를 한 칸으로 묶음, 단계 제목 옆에 '피부 2/5')
- <b>패널</b>: 영상 속 제품 → 내 제품(대체 · 해당 제품 없음) · 단계 제목 · 행동 가이드 · 진하기 게이지
  - 게이지: '레퍼런스보다 연해요 / 비슷해요 / 진해요' + 레퍼런스 위치선. 목표 구간·적당해요 판정 없음(자동 채점 제외)
  - 측정 불가: 가림·이탈·회전·거리·조명 시 회색 '지금은 잴 수 없어요' + 이유, 값 멈춤
  - 기본 위치 영역: '영상에서 위치를 찾지 못해 기본 위치로 보여 드려요'
  - 제품 없는 단계: 설명만 보고 '건너뛰기'(사진은 찍음)
- <b>준비 카드</b>: 제품 · 할 일 · 끝내는 기준. 부위 묶음의 첫 단계에만 띄우고, 여러 단계로 나뉜 묶음이면 '아이라인 · 4단계로 나눠 발라요'
  - 묶음 안 다음 단계는 카드 없이 시작하고 단계 제목 · 할 일을 잠깐 강조한다. 앞 단계와 제품이 다르면 '제품을 바꿔 주세요 · 제품 이름'
  - 그 단계 진하기 기준을 잡지 못했으면 그 단계만 카드를 띄운다
- <b>단계 넘기기</b>: '다음 스텝' / 마지막 '완성하기' → 부위 묶음의 마지막 단계에서 사진을 찍고 바로 다음
  - 단계 끝 안내: 묶음 사진을 찍은 뒤 하단에 안내 문장 최대 3줄(예: '섀도는 가이드보다 눈꼬리 쪽으로 넓게 발랐어요', '립은 레퍼런스와 비슷해요'). 점수·합격 판정 없음, 기록에 남기지 않음
  - 촬영 실패: '사진을 저장하지 못했어요' → 다시 찍기(사진 없이 넘어갈 수 없음)
- <b>중도 종료</b>: '튜토리얼을 종료할까요? 완료하지 않으면 기록과 사진이 남지 않아요' → 종료(홈) / 계속하기
- <b>관련</b>: GUIDE-003/006/007/008/011/013 · CAMERA-003/004

## 10. 완성

- <b>화면</b>: 'LOOK COMPLETE · N / N' · '영상 제목 · 완성했어요' · 마지막 단계 사진 · 출처(영상 제목·채널)
- <b>기록 저장</b>: '기록 저장 중…'(리포트 보기 비활성) → '기록을 저장했어요' / 실패 시 '기록을 저장하지 못했어요 · 다시 시도'(같은 실행으로 재요청 — 중복 기록 없음)
- <b>사진 없음</b>: '미촬영 · 사진 없이 완료했어요'
- <b>다음</b>: '리포트 보기'(스텝별 사진 · 사용한 제품) / 홈
- <b>관련</b>: GUIDE-010 · API-GUIDE-006

## 11. 마이페이지 — 내 파우치

- <b>화면</b>: 파우치 보드(종류별 일러스트 스티커) · 카테고리 필터 · 전체 목록 · 제품 추가. 빈 상태 '아직 등록한 제품이 없어요'
- <b>카테고리 9개 · 종류</b>
  - 베이스: 쿠션 · 파운데이션 · 컨실러 · 선크림 · 파우더 · 스틱
  - 아이: 섀도우 팔레트 · 마스카라 · 아이라이너 · 인조 속눈썹 / 브로우: 브로우 펜슬
  - 치크: 블러셔 · 하이라이터 · 컴팩트 / 립: 립스틱 · 립글로스 · 립틴트 · 립밤·팟 · 리퀴드 립
  - 스킨케어: 토너 · 세럼·앰플 · 크림 · 클렌징 폼 · 클렌징 오일 · 핸드·아이크림 · 마스크팩 · 미스트
  - 네일: 네일 폴리시 · 네일 파일 / 향수 / 도구: 브러시 · 퍼프 · 스펀지 · 뷰러 · 손거울 · 족집게 · 화장솜 · 면봉
  - 대체 후보 매칭은 메이크업 5개 카테고리만, 나머지는 보관만
- <b>등록·수정 시트</b>: 카테고리 → 종류(일러스트) → 브랜드·제품명 → 호수·컬러 목록 선택(스킨케어·향수·도구는 없음)
  - 목록에 없으면 직접 입력 + 색상(선택) · '모르겠어요' → '색상 정보가 없으면 대체 후보에서 빠져요'
  - 컬러 목록 조회 실패 → 다시 시도 / 직접 입력
  - 중복(같은 브랜드·제품명·호수) → '이미 파우치에 있는 제품이에요' + 저장 비활성
  - 수정: 모든 항목 수정 가능 / 삭제: '이 제품을 파우치에서 뺄까요? 다음 매칭부터 반영돼요. 이미 끝난 리포트는 바뀌지 않아요'
  - 카탈로그 검색 결과 목록 단계는 두지 않음
- <b>관련</b>: POUCH-002/003/004/005/006 · API-POUCH-008

## 12. 마이페이지 — 리포트

- <b>목록</b>: 최근 룩 카드(NEW · 단계 점 · 'N / N STEP 완료 · 대체 제품 N개') + Past looks. 빈 상태 '아직 완료한 메이크업이 없어요' → 영상 고르러 가기
- <b>상세</b>: 날짜 · 단계 수 · 제목(영상 제목) · FINAL LOOK · Step captures(부위 묶음별 내 얼굴, 없으면 '미촬영') · Step guide(순서 · 레퍼런스 제품 / 내가 쓴 제품 · 동일 제품 / 대체 / 없음)
- <b>삭제</b>: '이 리포트를 삭제할까요? 단계 사진도 함께 삭제돼요' → 삭제 중 → 목록 / 실패 시 다시 시도
- 진하기 결과는 기록하지 않음(채점 제외)
- <b>관련</b>: REPORT-001/002/003/004 · API-REPORT-003

## 남은 확인 필요

- 영상 입력의 내 가이드 목록 '이어서 하기' 정렬: 중도 종료 시 기록이 남지 않는다는 정책과 충돌 → 삭제하거나 '끝까지 못 한 가이드(다시 시작)'로 의미 변경 필요
- 단계 사진 보관 기간(개인정보 처리방침)
- 얼굴 등록 이미지 장수 확장(정면 1장 → 정면·좌·우 3장, P1)
- 로그인 시도 제한 횟수·시간, 일일 분석 한도·초기화 시각, 인식 알림 임계값(비기능명세)
- 온보딩 노출을 기기 단위 → 계정 단위로 바꿀지
