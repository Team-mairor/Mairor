# 찾은 영역에 바른 방향 화살표(`arrow`)가 함께 올 수 있습니다

- 작성: 김현수

- 날짜: 2026-11-14
- 기한: 급하지 않습니다. 화면 확인만 부탁드립니다
- 관련 Jira: S15P31A306-431

## 요청 배경

AI가 찾은 영역(`extracted`) 묶음의 `guides`에, 테두리(`polygon`) 뒤로 바른 방향(`arrow`)이 0개나 1개 올 수 있게 형식을 넓혔습니다.

```json
{ "type": "arrow", "from": { "triangle": 37, "bary": [0.21, 0.52, 0.27] }, "to": { "triangle": 267, "bary": [0.18, 0.47, 0.35] } }
```

- FE `frontend/src/features/face/types.ts`의 `arrow` 도형, `AreaGuideSet.guides`와 같은 모양이라 FE 코드는 바꾸지 않았습니다.
- 화살표만 있는 묶음은 보내지 않습니다. 기본 가이드(`template`) 단계는 그대로입니다.
- **지금 운영에서는 화살표가 오지 않습니다.** 방향은 단계 동안의 사진으로 찾는데 처리기가 그 사진을 아직 뽑지 않습니다. 처리기와 AI 설정이 바뀐 뒤에도 순서가 뚜렷한 영역(시험 영상에서 3분의 1 안팎)에만 옵니다.
- 형식 설명: `shared/guide-area/README.md`의 「바른 방향 (`arrow`)」, 근거: `docs/experiments/GUIDE_APPLY_DIRECTION.md`
