## 요청 배경

가이드 영역을 만드는 시간을 줄이면서 AI 서버 설정 세 칸을 더했습니다(`ai/app/core/config.py`, `ai/.env.example`).

| 설정 | 기본값 | 뜻 |
| --- | --- | --- |
| `AREA_LINES` | 2 | 영역 작업 하나 안에서 단계를 이 수만큼 줄로 나눠 동시에 만든다 |
| `AREA_ONNX_THREADS` | 1 | 서버가 켜질 때 가림 찾기 모델을 이 일꾼(스레드) 수로 연다 |
| `AREA_OPENCV_THREADS` | 1 | 서버가 켜질 때 OpenCV 일꾼 수 |

로컬 PC를 AI 서버(m6i.large, 2 vCPU)처럼 코어 2개로 묶어 정한 값입니다.

- 일꾼 수: 가림 찾기 일꾼 2명이면 1명보다 영역 만들기가 10% 넘게 느렸습니다. 코어 2개(물리 코어 하나를 나눈 것)를 두고 서로 기다리기 때문입니다. 설정이 없으면 라이브러리가 서버 사양을 보고 일꾼 수를 정하는데, 2명을 고르면 이렇게 느려져서 값을 정해 두었습니다.
- 줄 수: 두 줄로 나누면 한 줄보다 영역 만들기가 18% 빨랐습니다.
- 최대 메모리는 31분 영상에서 약 4.3GB → 3.3GB로 줄었고, AI 컨테이너 상한(7G) 안입니다.

재는 방법과 숫자는 [가이드 영역 생성 속도·메모리 줄이기](../experiments/GUIDE_AREA_SPEED.md)에 있습니다.
