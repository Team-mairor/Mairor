# 기본 아이섀도 가이드에 눈 아래 안내 추가 요청

- 작성: 김현수
- 받는 사람: 한서윤
- 날짜: 2026-11-01
- 기한: 2026-11-02 (Sprint3 끝)
- 관련 Jira: S15P31A306-220

## 요청 배경

AI가 아이섀도 단계에서 바른 곳을 찾지 못하면 도형 없이 기본 가이드 이름만 보냅니다.

```json
{ "subStepId": "s17-1", "order": 1, "status": "template", "reasons": ["eyeshadowColorNotFound"], "templateId": "eyeshadow", "guideSets": [] }
```

이때 FE는 기본 아이섀도 가이드(`frontend/src/features/guide/default-guides.ts`의 `eyeshadow`, 윗눈꺼풀부터 쌍꺼풀 라인 높이까지의 띠)를 그립니다.

그런데 단계 정보에는 화장 종류(`eyeshadow`)만 있고, 윗눈두덩에 바르는 단계인지 애교살(눈 아래)에 바르는 단계인지는 없습니다. GO지승 「완성도 up」 영상(VxAXD6PP76I)에서 아이섀도로 분류되는 챕터 4개 중 3개는 눈 아래에 발랐습니다.

| 챕터 (초) | 실제로 바른 곳 |
| --- | --- |
| 아이섀도우 (640~698) | 윗눈두덩 + 눈 아래 |
| 애교살 (698~782) | 눈 아래 |
| 애교살 (1152~1183) | 눈 아래 |
| 마무리 음영 (1191~1223) | 눈꼬리 아래 |

애교살(698~782초)에서 바른 곳을 얼굴 지도(1024×1024)에 칠한 정답은 12,450칸이고, 그중 눈 아래가 11,370칸, 눈 위가 37칸입니다. 이런 단계에서 AI가 바른 곳을 못 찾으면 지금 기본 가이드는 바른 곳과 겹치지 않는 윗눈꺼풀을 안내합니다.

AI는 붉은 기가 늘어난 곳으로 섀도를 찾아서, 흰색·회색처럼 붉은 기가 없는 섀도나 아주 연한 섀도는 못 찾음으로 보냅니다. 애교살에는 흰색 섀도를 많이 쓰므로 이 경우가 자주 생길 수 있습니다.

## 요청 내용

- [ ] 튜토리얼 기본 아이섀도 가이드가 눈 아래(애교살 자리)도 함께 안내하게 바꿔 주세요. 예를 들어 지금 윗눈꺼풀 띠는 두고, 아래 속눈썹 선부터 그 아래로 얇은 띠를 더하는 방식입니다. 최종 모양과 안내 문구는 화면에서 보고 정해 주세요
- [ ] AI가 찾아서 보내는 아이섀도 영역은 눈을 감싸는 모양일 수 있어서, 묶음마다 그 눈을 `exclude`에 넣어 보냅니다 (`"region": "leftEye", "exclude": ["leftEye"]`). 이미 반영된 `exclude` 처리로 눈 구멍이 뚫려 그려지는지 확인해 주세요
