# 가이드 게이지 기준·미리보기 레이어 전달 계약 확정 요청

- 작성: 김서연 (BE)
- 받는 사람: S15P31A306-437 AI 담당자, FE와 협의
- 날짜: 2026-11-11
- 기한: S15P31A306-397 저장·조회 구현 계약 확정 전
- 관련 Jira: [S15P31A306-437](https://ssafy.atlassian.net/browse/S15P31A306-437), [S15P31A306-397](https://ssafy.atlassian.net/browse/S15P31A306-397)

## 요청 배경

397은 AI가 만든 가이드 게이지 기준과 미리보기 레이어를 저장하고 기존 가이드 조회 응답으로 FE에 전달한다. 현재 BE는 AI 콜백의 `guide`·`area` JSON을 보존하며, 가이드 조회의 `targetColor`는 비어 있다. AI 출력의 실제 위치·타입·버전과 레이어 전달 방식이 정해지지 않아 BE가 필드나 의미를 임의로 추가하면 안 된다.

이 문서는 구현 규격을 BE에서 선결정하는 문서가 아니라, AI 437 결과와 FE 사용 방식에 필요한 결정 및 예시를 요청하는 문서다. 실제 목표값과 시험 데이터는 AI 측정·튜닝 결과에 따라 별도로 채운다.

## 결정 및 회신 요청

1. **데이터 단위와 식별자**
   - 게이지 기준을 `stepId`에 둘지, `subStepId`마다 둘지 정해 주세요. 아이섀도처럼 한 단계 안에서 영역/색 기준이 다른 경우의 예시도 포함해 주세요.
   - 기준 데이터가 없는 단계, 측정 불가, 적용 제외를 구분하는 규칙과 표현을 알려 주세요.

2. **게이지 기준 필드와 의미**
   - 기준 색상(예: HEX·Lab), 화장 효과, 진하기(계획상 0~100)의 필드명·자료형·범위·단위·null 규칙을 확정해 주세요.
   - Lab 기준을 사용한다면 색 공간/관찰 조건 등 값의 해석에 필요한 기준을 적어 주세요.
   - 미측정·기준 없음 사유를 기계적으로 분기할 수 있는 코드와 설명 규칙을 알려 주세요.
   - 라인 형태나 영역별 유지 시간 같은 항목이 이번 437 범위인지 명시해 주세요. 범위에 포함된다면 각각의 측정 의미와 예시를 별도 필드 계약으로 제안해 주세요. 현재 437 설명에는 유지 시간 계약이 없어 BE가 이를 추가하지 않습니다.

3. **미리보기 레이어 전달 방식**
   - 콜백 JSON에 직접 담을지, 별도 파일/객체로 제공할지 결정해 주세요.
   - 별도 파일이면 파일 형식·버전·참조 키/URL·좌표계·레이어 식별자·색/마스크 구조·크기 제한·생성 실패 처리와 보존 기간을 알려 주세요.
   - FE의 현재 fixture(`/fixtures/layers/sample.json`)에서 실제 가이드 레이어로 전환할 때 필요한 최소 계약을 FE와 확인해 주세요.

4. **AI→BE 결과 위치와 버전 호환**
   - 완료 콜백과 상태 조회 결과에 새 데이터를 동일하게 포함하는지, `guide`와 `area` 중 어느 객체의 어떤 경로가 원본인지 정해 주세요.
   - 기존 결과에는 새 필드가 없는 상태를 허용할지, 공유 스키마/API 버전을 올릴지 알려 주세요.
   - 새 필드를 포함한 대표 완료 payload와 구버전 payload 예시를 함께 제공해 주세요.

5. **AI→FE 사용 계약**
   - FE가 목표 기준으로 사용하는 값과 FE가 카메라에서 실시간 계산할 값을 구분해 주세요.
   - FE 실시간 계산의 입력·출력, 측정 불가 상태, 단계 평가 결과/안내 문구 키가 437 결과 데이터와 어떤 식으로 연결되는지 정리해 주세요. AI가 실시간 사용자 측정값을 BE로 지속 전송하는 범위가 아니라면 그 경계도 명시해 주세요.

## 원하는 회신 산출물

- 갱신된 `shared/guide-area` 스키마·README 및 유효/경계 사례 JSON
- `guide_area_builder`와 완료 콜백/상태 조회에 새 값이 채워지는 예시
- 기존 AI 결과를 포함한 스키마 검증 결과와 실패/미측정 사례
- 게이지 기준·레이어를 소비하는 FE 요청 문서 또는 FE와 합의한 계약
- 위 2번의 추가 지표가 미정이면, 이번 범위에서 제외한다는 명시

## BE 후속 처리

계약 회신 전에는 새 엔티티 필드·DB 컬럼·DTO 필드·임시 JSON 경로를 만들지 않는다. 회신 후 BE는 기존 콜백 JSON 저장 및 `GET /api/v1/guides/{guideId}` 조회 경로를 기준으로 저장 위치, 응답 호환성, 필요한 마이그레이션 여부와 테스트 범위를 정리해 397 구현을 이어 간다.
