## 요청 배경

FE는 S15P31A306-484 브랜치에서 같은 카메라 세션의 얼굴 등록 단계에 맨얼굴·흰자 기준 15장과 노출·화이트밸런스 잠금값을 모아 튜토리얼에서 재사용합니다. 사용자 흰자는 요청해 주신 새 규칙으로 고르지만, 레퍼런스 흰자를 만드는 AI도 같은 규칙으로 바뀌어야 두 값을 같은 기준으로 비교할 수 있습니다.

가림 판정은 FE에서 브라우저 Worker로 실행할 예정입니다. 저장소에는 입력 크기를 바꿀 수 있는 내보내기 도구만 있고 브라우저가 직접 받을 모델 파일은 없으므로, FE가 AI 운영 코드를 수정하지 않고 소비할 수 있는 모델 산출물이 필요합니다.

## 요청 내용

- [ ] 레퍼런스 흰자 추출을 아래 FE 규칙과 같게 바꿔 주세요.
  - 사진의 `leftEye`·`rightEye` 다각형을 눈 가로 길이의 5%만큼 안쪽으로 줄입니다.
  - 홍채 중심 `468`·`473`과 둘레 `469~472`·`474~477`의 지름으로 구한 반지름에 1.2를 곱해 홍채 영역을 뺍니다.
  - 사진마다 밝기 상위 25%를 고르고 채널 하나라도 250 이상인 반사광을 뺍니다.
  - 유효한 15장의 사진별 흰자 색 중앙값을 최종 흰자 색으로 사용합니다.
  - `ai/app` 구현·AI 테스트·`shared/gauge` 설명과 기대값을 함께 갱신해 주세요.
- [ ] 브라우저용 가림 모델 산출물을 전달해 주세요.
  - `ai/tools/gauge/export_occlusion_web.py`로 만든 가변 입력 ONNX를 Git LFS 또는 합의한 정적 배포 경로에 둡니다.
  - FE 입력은 384×384를 사용합니다. 256은 사용하지 않습니다.
  - 입력 이름·RGB 정규화 값·얼굴 자르기 배율 1.4·출력 이름과 모양·가림 라벨 19를 문서에 확정해 주세요.
  - 파일 크기와 SHA-256, 모델 이용 조건을 함께 알려 주세요.
  - 384 입력이 512와 같은 판정을 내는 AI 테스트를 유지해 주세요.
- [ ] 위 두 변경이 들어간 AI MR 링크와 FE가 적용을 시작해도 되는 시점을 이 문서 또는 MR에 알려 주세요.
