## 요청 배경

AI는 다음 주에 실제 운영 요청 한 번으로 가이드 영역을 확인하고 구간별 시간을 잽니다. 확인할 것은 두 가지입니다.

- BE가 Gemini로 뽑은 단계로도 9개 부위가 「찾음 · 기본 영역 · 해당 없음 · 실패」 중 하나로 빠짐없이 콜백에 들어가는지
- AI 영역 작업 안의 구간별 시간(사진 받기 · 얼굴 점 · 사진 판정 · 영역 만들기)

S15P31A306-364(운영 E2E와 단계별 시간 측정)와 같은 실행이라, 운영을 두 번 돌리지 않고 364 실행 한 번의 기록을 같이 보려고 합니다. AI 작업 기록(구간별 시간과 콜백 본문)은 Phoenix에 30일 남아서, 작업 번호만 있으면 실행 뒤 언제든 찾을 수 있습니다. Phoenix는 AI가 만든 작업 ID로 기록을 찾기 때문에 BE 분석 `jobId`와 함께 AI 작업 ID가 필요합니다.

## 요청 내용
