## 요청 내용

- [ ] **README대로 계산**: [shared/gauge/README.md](../../shared/gauge/README.md)의 「색 계산 공통」 · 「계산 순서」 · 「게이지 값 계산」 · 「측정 불가 판정과 값 안정화」 · 「고른 제품에 따라 보이기」대로 계산해 주세요. 위 표에서 바뀐 곳이 특히 중요합니다. 지도 펴기의 삼각형 · 테두리 칠하기는 README 「칠하기 코드」를 그대로 써 주세요. 픽셀 가운데에서 재는 흔한 칠하기로는 영역 칸 수가 달라집니다.
- [ ] **시험 데이터로 맞춰 보기**: FE 시험에서 `shared/gauge/`의 `measure` · `stability` · `substitute` · `pipeline` 네 파일을 직접 읽어 사례마다 같은 값이 나오는지 봐 주세요. 허용 오차는 README 「FE에서 맞춰 보는 법」에 있습니다. **`pipeline.v1.json`은 새로 만든 사진부터 시험**입니다. `fixtures/pipeline/*.png` 사진과 얼굴 점에서 시작해 펴기 · 칸 색 · 기준 · 조명 빼기 · 영역 칸 · 게이지 값까지 한 번에 맞춰 볼 수 있습니다. 사진은 사람 얼굴이 아니라 합성 얼굴입니다.
- [ ] **결과 JSON 주기**: 시험에서 낸 값을 README 「FE에서 맞춰 보는 법」 모양의 JSON으로 저장해 MR에 올리거나 보내 주시면, AI가 `ai/tools/gauge/check_fe_readings.py`로 한 번 더 확인하고 결과를 이 문서에 적겠습니다.
- [ ] **계산은 worker에서, 줄여도 되는 계산 쓰기**: 0.2초마다 하는 계산을 README 「계산 순서」 그대로 하면 이 노트북 브라우저 worker에서도 한 번에 161ms였고, 갤럭시탭 S6는 약 4.5배 느릴 것으로 봅니다(약 730ms). README 「계산량」의 네 가지를 함께 쓰시면 31ms(탭 S6 어림 140ms)로 줄고 게이지 값은 허용 오차 안입니다.
  1. 1024 지도는 지금 하위 단계 영역 칸에 드는 픽셀만 펴기
  2. 조명 변화 · 흔들림은 256 지도로 따로 펴서 재기
  3. 조명 변화는 64칸에서 재서 128칸으로 선형 확대
  4. 흔들림은 행 · 열 번호가 모두 짝수인 칸만으로 재기

  지도 전체를 256 · 512로 펴거나 가장 가까운 픽셀로 고르면 값이 카메라 잡음만큼 바뀌어 쓰지 않습니다. 얼굴 점 모델 · 가림 모델과는 다른 worker를 권합니다.
