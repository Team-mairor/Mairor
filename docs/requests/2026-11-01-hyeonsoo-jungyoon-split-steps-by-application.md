# 바르는 자리가 바뀌면 단계 나누기 요청

## 요청 배경

AI는 가이드 입력의 단계마다 단계 구간(`startSeconds` ~ `endSeconds`) 직전 사진과 직후 사진의 얼굴 색을 비교해, 그 단계에서 새로 바른 곳을 영역으로 만듭니다. 눈썹은 직전 1초 · 직후 2초, 아이섀도는 직전 2초 · 직후 1초 사진을 씁니다.

그래서 한 단계 안에서 여러 자리를 차례로 바르면 그 자리들이 영역 하나로 합쳐집니다. GO지승 「완성도 up」 영상(VxAXD6PP76I)의 아이섀도우 챕터(640~698초)는 섀도 하나로 윗눈두덩을 바른 뒤 눈 밑을 발랐는데, 두 자리가 눈꼬리에서 이어진 말굽 모양 하나로 나옵니다. 튜토리얼에서는 윗눈두덩 → 눈 밑처럼 바른 차례마다 따로 보여 주려고 합니다.

AI 쪽에서 단계 안 사진을 시간 순서로 보며 나눠 보는 실험도 했습니다.

| 자리 | 칠해진 때 |
| --- | --- |
| 윗눈두덩 | 640~672초 (눈앞머리에서 눈꼬리 쪽으로 쓸어 감) |
| 눈 밑 | 684초쯤 |

- 중간에 쉬는 틈이 뚜렷할 때만 나뉘었고, 바르는 중 사진은 브러시 · 손 · 눈 감음 때문에 잡음이 많았습니다.
- 무엇을 어디에 바르는지는 영상과 자막을 함께 보는 단계 추출이 더 잘 압니다. 단계를 처음부터 나눠 주시면 AI는 지금 방식 그대로 단계마다 그 차례의 영역을 만들고, 단계마다 설명 글도 따로 붙습니다.

## 요청 내용

- [ ] 같은 화장 종류라도 바르는 자리가 바뀌면 단계를 나눠 주세요. 예를 들어 아이섀도 베이스(윗눈두덩 전체) → 눈꼬리 음영 → 눈 밑입니다. 위 영상의 아이섀도우 챕터라면 윗눈두덩(640~672초쯤)과 눈 밑(683~698초쯤) 두 단계입니다
- [ ] 단계 경계(`startSeconds` · `endSeconds`)를 실제로 바르기 시작한 때와 끝난 때, 곧 브러시나 손이 얼굴에서 떨어진 때에 맞춰 주세요. AI는 경계 직전 · 직후 1~2초 사진을 비교하므로, 경계가 바르는 도중에 걸리면 바른 곳의 일부만 잡힙니다

레퍼런스 프레임 전달 요청(S15P31A306-310에서 반영하고 닫음, 규칙은 [backend/README.md](../../backend/README.md) "프레임 추출")의 간격 규칙(기본 초당 2장, 단계 시작 · 끝 앞뒤 3초는 초당 10장)은 단계 경계를 따라가므로, 단계를 나눠도 규칙은 바꾸지 않아도 됩니다.

## 참고 (FE · 기획)

- 단계가 잘게 나뉘면 튜토리얼에서 단계마다 있는 게이지와 사진 찍기도 그만큼 늘어납니다.
