## 2. 로컬 빌드 · 실행

포트: DB `5432`(compose 기본), Redis `6379`, BE `8080`, AI `8000`, FE `3000`.

### 2.1 DB · Redis

```bash
cp .env.example .env                 # POSTGRES_PASSWORD 를 정한다
docker compose up -d postgres redis
```

빈 DB로 시작하면 dev 프로파일이 테이블을 만든다(`ddl-auto=update`). 운영과 같은 데이터로 보려면 [db/README](db/README.md#복원)대로 덤프를 넣는다.

### 2.2 백엔드

```bash
cd backend
cp .env.example .env                 # DB_URL · DB_USERNAME · DB_PASSWORD 를 위 값과 맞춘다
./gradlew bootRun                    # 또는 ./gradlew bootTestRun (Testcontainers 가 postgres 를 직접 띄움)
./gradlew spotlessCheck test build   # CI 와 같은 검사 (Docker 필요)
```

- 확인: http://localhost:8080/api/health → `{"status":"UP"}`
- API 문서: http://localhost:8080/api/swagger-ui/index.html (dev에서만)

### 2.3 프론트엔드

```bash
cd frontend
npm ci
cp .env.example .env.local           # API_PROXY_TARGET=http://localhost:8080
npm run dev                          # http://localhost:3000
npm run build                        # 정적 파일 → out/
```

카메라는 HTTPS 또는 `localhost`에서만 열린다. 폰에서 볼 때는 `npm run dev:https`([frontend/README](../frontend/README.md#폰에서-카메라-테스트)).

### 2.4 AI 서버

```bash
cd ai
cp .env.example .env                 # GMS_API_KEY 를 넣는다
uv sync
uv run uvicorn app.main:app --reload --port 8000
uv run ruff check . && uv run pytest # CI 와 같은 검사
```

확인: http://localhost:8000/health

### 2.5 영상 전처리기

```bash
cd video-processor
pip install -r requirements.txt
cp .env.example .env                 # GMS · AWS · PROCESSOR_API_* 값
python pipeline.py --url "https://www.youtube.com/watch?v=RBm4rzufBV0"   # 영상 한 편만 시험
python pipeline.py --serve           # BE 작업을 5초마다 가져가 처리 (운영 연결 모드)
```

### 2.6 이미지 빌드 (CI와 같은 방법)

저장소 루트에서 빌드한다(`shared/`를 함께 넣기 때문).

```bash
docker build -f frontend/Dockerfile -t mairor-nginx .
docker build -f backend/Dockerfile  -t mairor-backend .
docker build -f ai/Dockerfile       -t mairor-ai .
docker build -f deploy/Dockerfile   -t mairor-deploy .     # 서버에 놓을 배포 파일 묶음
```

> (선택) 화장품 수집 워커(ECS Fargate) 이미지는 `docker build -f ai/Dockerfile.collector -t mairor-collector .`로 빌드한다. 실행 환경 변수와 SQS·ECS 설정은 [`ai/docs/CATALOG_WORKER.md`](../ai/docs/CATALOG_WORKER.md)에 정리되어 있다.

## 4. 배포

### 4.1 서버 최초 준비 (1회)

1. **네트워크**: VPC에 퍼블릭 서브넷(ALB · EC2) · 프라이빗 서브넷(RDS). EC2 두 대에 Elastic IP.
2. **보안 그룹**

   | 대상 | 인바운드 |
   | --- | --- |
   | ALB | 80 · 443 모두 |
   | BE 서버 | 8081 · 8082 ← ALB, 8090 ← AI 서버 보안 그룹. **22 열지 않음** |
   | AI 서버 | 8000 ← BE 서버 보안 그룹 |
   | RDS | 5432 ← BE 서버 보안 그룹 |

3. **ALB**: 대상 그룹 `mairor-app-tg`(BE 서버 8081 · 8082, 헬스 `/nginx-health`), 443 리스너에 ACM 인증서(`mairor.co.kr`, `www`), 80은 443으로 301. 등록 해제 지연 30초.
4. **EC2 역할**: SSM 관리형 정책(Session Manager · Run Command), ECR 읽기, Parameter Store `/mairor/prod/*`(BE) · `/mairor/ai/*`(AI) 읽기, S3 `mairor-prod-media` 읽기 · 쓰기(BE), ELB 대상 등록 · 해제(BE), CloudWatch Logs 쓰기.
5. **서버 패키지**: Docker Engine + Compose 플러그인, AWS CLI v2, `python3`, `/opt/mairor` 폴더(root).
6. **RDS**: PostgreSQL 17, DB 이름 `mairor`, 마스터 계정 `mairor`. 테이블은 [db/README](db/README.md)대로 먼저 넣는다.
7. **Parameter Store**: [§ 3.2](#32-백엔드-실행할-때-주입) · [§ 3.3](#33-ai-서버-실행할-때-주입) 값을 넣는다. 비밀값은 SecureString.
8. **ECR 저장소 4개**(`mairor-nginx` · `mairor-backend` · `mairor-ai` · `mairor-deploy`), 수명 주기 규칙 "최근 10개만".
9. **GitLab CI 변수**: [§ 3.1](#31-빌드할-때-들어가는-값)의 CI 변수.
10. **인프라 서버(모니터링)**: [infra/README "처음 준비"](../infra/README.md#처음-준비-한-번). Caddy의 `remote_ip`를 BE 서버 Elastic IP로.

### 4.2 Nginx 설정

설정 파일은 이미지 안에 있다. 서버에서 따로 고치지 않는다.

**`frontend/nginx/static.conf`** (`mairor-nginx`, 슬롯마다 1개)

| location | 동작 |
| --- | --- |
| `/` | `try_files $uri $uri.html $uri/index.html =404`, `Cache-Control: no-cache` |
| `/_next/static/` | 1년 캐시(`immutable`) |
| `/mediapipe/` · `/models/` | 7일 캐시 (얼굴 추적 모델 · wasm) |
| `/api/` | `proxy_pass http://api:8080` (Docker DNS `127.0.0.11`로 매번 찾음), `client_max_body_size 6m`, `X-Forwarded-*` 전달 |
| `/api/v1/internal/ai/` | **404** (AI 콜백은 바깥에서 막는다) |
| `= /nginx-health` | `200 ok` (ALB · compose 헬스) |

gzip: css · js · json · wasm · svg.

**`deploy/callback-gw.conf`** (`callback-gw`, 8090)

- `/api/v1/internal/ai/`만 `10.0.0.0/16`(VPC)에서 받아 살아 있는 `api`로 넘긴다. 연결 3초 · 읽기 15초, 실패하면 다른 슬롯으로 1번 더(`proxy_next_upstream_tries 2`), 본문 20 MB.
- 그 밖의 경로는 404.

### 4.3 자동 배포 (GitLab CI)

`master`에 머지되면(`ci/deploy.yml`):

1. `repo-guard` — 커밋된 `.env` · `*.pem` · `*.key`가 있으면 실패
2. `build-images` — 이미지 4개 빌드 → ECR push (태그 = 커밋 해시 8자리)
3. `deploy` — SSM Run Command로 **AI 서버(`deploy-ai.sh`) → BE 서버(`deploy.sh`)** 순서
   - BE는 슬롯 a → b → worker 순서로 하나씩: 대상 그룹에서 빼기 → 30초 연결 정리 → 교체 → 헬스 → 다시 넣기 → ALB 정상 확인
   - 중간에 실패하면 그 서버는 스스로 이전 태그로 되돌리고 잡이 빨강
   - 결과는 서버의 `releases.log` · `releases-ai.log`에 남는다
4. `rollback`(수동) — 잡 이름을 눌러 `ROLLBACK_TAG`에 태그를 넣고 실행

배포는 4~6분, 그동안 사이트는 끊기지 않는다.

### 4.4 BE ↔ AI 서버 연결

| 방향 | 주소 | 막는 것 |
| --- | --- | --- |
| BE → AI 가이드 요청 | `AI_BASE_URL=http://<AI 사설 IP>:8000` | AI 보안 그룹 8000은 BE 서버에서만 |
| AI → BE 결과 · 진행 알림 | `AI_CALLBACK_BASE_URL=http://<BE 사설 IP>:8090/api` | BE 보안 그룹 8090은 AI 서버에서만, 바깥 nginx는 이 경로 404 |

서버 IP가 바뀌면 이 두 값을 고치고 BE를 다시 배포한다. 중지 · 시작은 사설 IP가 그대로라 고칠 것이 없다.

### 4.5 수동 배포 (CI가 안 될 때)

AWS 콘솔 → EC2 → 연결 → **Session Manager** → `sudo -i`

```bash
TAG=<커밋 해시 8자리>
REG=$(aws sts get-caller-identity --query Account --output text).dkr.ecr.ap-northeast-2.amazonaws.com
aws ecr get-login-password --region ap-northeast-2 | docker login -u AWS --password-stdin "$REG"
docker pull -q "$REG/mairor-deploy:$TAG"
id=$(docker create "$REG/mairor-deploy:$TAG") && docker cp "$id:/deploy/." /opt/mairor/ && docker rm "$id"
/opt/mairor/deploy.sh "$TAG"      # AI 서버는 deploy-ai.sh, 되돌리기는 rollback.sh · rollback-ai.sh
```

`deploy 완료`가 나올 때까지 Session Manager 탭을 닫지 않는다.

## 5. 배포 시 특이사항

### 5.1 영상 전처리기는 노트북에서 돈다

- 운영 EC2(AWS IP)는 유튜브가 봇으로 막아 영상을 받을 수 없다. 그래서 `ANALYSIS_PROCESSOR_ENABLED=true`로 두고 **팀 맥북**이 작업을 가져간다.
- 시연 · QA 동안 맥북에서 `python pipeline.py --serve`를 켜 둔다. 잠자기를 막는다(`caffeinate -dimsu`).
- 노트북이 5분 넘게 작업을 안 가져가면 Grafana 알림 "노트북 응답 없음", 30분이면 그 분석은 `PROCESSOR_TIMEOUT`으로 실패한다.

### 5.2 DB 스키마는 손으로 적용한다

- 운영은 `ddl-auto=validate`, Flyway 없음. 테이블 · 칸이 없으면 앱이 뜨지 않는다.
- 스키마를 바꾸는 MR은 **머지 전에** `backend/src/main/resources/db/upgrade/<이슈번호>-*.sql`을 운영 DB에 먼저 적용한다(Session Manager에서 `postgres:17` 컨테이너의 `psql`).
- 배포 스크립트는 얼굴 등록 테이블을 읽기 전용으로 미리 검사(`check-camera-schema.sh`)하고, 없으면 교체 전에 멈춘다.

### 5.3 HTTPS와 세션 쿠키

- 세션 쿠키 이름이 `__Host-sessionId`, `Secure` · `HttpOnly` · `SameSite=Strict`다. HTTPS 주소에서만 브라우저가 저장한다.
- 로컬 `http://localhost`는 브라우저가 예외로 받아 준다. 다른 HTTP 주소(사설 IP 등)로 접속하면 로그인이 안 된다.
- 카메라(getUserMedia)도 HTTPS · localhost에서만 열린다.

### 5.4 master 머지 = 운영 배포

- `ci/deploy.yml`에는 바뀐 폴더 조건이 없다. **문서만 바꾼 MR도 머지하면 이미지 빌드 · 배포가 돈다.**
- 머지는 fast-forward만, 파이프라인 통과 필수, master 직접 push 금지.
- 분석이 돌고 있거나 시연 중일 때는 머지하지 않는다(AI 서버가 다시 뜨면 진행 중인 가이드 계산이 끊긴다).

### 5.5 AI 서버 크기

| 때 | 인스턴스 | compose `ai` 상한 | `AREA_LINES` |
| --- | --- | --- | --- |
| 시연 기간 | `m6i.2xlarge` (8 vCPU · 32 GB) | `cpus: "8"` · `memory: 24G` | `6` |
| 평소 | `m6i.large` (2 vCPU · 8 GB) | `cpus: "2"` · `memory: 7G` | `2` |

키울 때는 **서버 먼저**, 줄일 때는 **compose 상한 먼저**. 순서가 바뀌면 컨테이너가 서버보다 큰 CPU를 요구해 뜨지 않는다. 자세한 순서는 [deploy/README "AI 서버 크기"](../deploy/README.md#ai-서버-크기-s15p31a306-416).

### 5.6 비용 · 정지

월 상한 $300. 시연 외 기간에는 EC2 두 대 중지 + RDS 일시 중지(7일 뒤 스스로 켜짐). 재개는 RDS → `mairor-ai` → `mairor-app` 순서. [deploy/README "비용 · 정지 · 재개"](../deploy/README.md#비용--정지--재개-s15p31a306-416)

### 자주 나오는 문제

| 증상 | 원인 | 해결 |
| --- | --- | --- |
| 배포 첫 줄에서 `Parameter Store 에 /mairor/prod/XXX 가 없다` | 필수값 누락 | § 3.2의 ✅ 값을 넣는다 |
| api가 `missing table` · `missing column`으로 재시작 반복 | 스키마 미적용 | [db/README](db/README.md) · § 5.2 |
| api가 `allowed-origins` 관련으로 기동 실패 | `ALLOWED_ORIGINS` 비어 있음 | 실제 접속 주소를 넣는다 |
| 로그인 응답은 200인데 바로 로그아웃됨 | HTTP로 접속 | HTTPS 주소로 접속 |
| Google 로그인에서 `redirect_uri_mismatch` | GCP 등록 주소와 다름 | GCP 콘솔과 `GOOGLE_REDIRECT_URI`를 같게 |
| 분석이 "영상 받는 중"에서 멈춤 | 노트북 처리기가 꺼져 있음 | § 5.1 |
| 분석이 `ANALYSIS_TIMEOUT` | AI 서버 콜백이 BE에 안 닿음 | `AI_CALLBACK_BASE_URL` · 8090 보안 그룹 |
| Grafana에 앱 서버 데이터 없음 | BE 서버 EIP가 Caddy `remote_ip`와 다름 | `infra/caddy/Caddyfile` 수정 후 `infra/` 배포 |

### 롤백

CI `rollback` 잡에 `ROLLBACK_TAG`를 넣어 실행하거나, 서버에서 `/opt/mairor/rollback.sh <태그>`(AI는 `rollback-ai.sh`). `releases.log`에 `ok`로 남은 태그만 된다.
