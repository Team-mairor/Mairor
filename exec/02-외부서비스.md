# 2. 외부 서비스

마이러가 쓰는 외부 서비스와 가입 · 키 발급 방법, 그 키를 넣는 곳을 정리한다.
**키 값은 이 문서와 저장소에 적지 않는다.** 운영 값은 SSM Parameter Store에 있다([01 § 7.2](01-포팅매뉴얼.md#72-비밀값이-있는-곳-저장소에-없음)).

## 한눈에

| 서비스 | 무엇에 쓰나 | 가입 · 발급 | 넣는 곳 |
| --- | --- | --- | --- |
| [SSAFY GMS](#1-ssafy-gms--llm) | Claude(가이드 설명 · 화장품 분류), Gemini(영상 단계 찾기) | SSAFY 계정 | `GMS_API_KEY`, `GEMINI_API_KEY` |
| [Google OAuth](#2-google-oauth-소셜-로그인) | Google 계정 로그인 · 가입 | GCP 콘솔 | `GOOGLE_CLIENT_ID` · `GOOGLE_CLIENT_SECRET` · `GOOGLE_REDIRECT_URI` |
| [Gmail SMTP](#3-gmail-smtp-인증-메일) | 가입 인증번호 · 비밀번호 재설정 메일 | Google 계정 + 앱 비밀번호 | `MAIL_USERNAME` · `MAIL_PASSWORD` |
| [YouTube Data API v3](#4-youtube) | 영상 검색 · 영상 정보(제목 · 채널 · 썸네일) | GCP 콘솔 | `YOUTUBE_API_KEY` |
| [YouTube 영상 받기 (yt-dlp)](#4-youtube) | 분석할 영상 원본 받기 | 가입 없음 | 노트북 처리기 |
| [AWS](#5-aws) | 서버 · DB · 저장소 · 배포 · 로그 | AWS 계정 | IAM 역할 · CI 변수 |
| [Discord 웹훅](#6-discord-웹훅) | 노트북 처리기 알림 | Discord 서버 관리 권한 | `DISCORD_WEBHOOK_URL` |
| [MediaPipe](#7-그-밖) | 브라우저 얼굴 추적, AI 서버 얼굴 점 찾기 | 가입 없음 (모델 동봉) | – |
| [Let's Encrypt](#7-그-밖) | 모니터링 서버 HTTPS | 가입 없음 (Caddy 자동) | – |
| [화장품 브랜드 공식 홈](#7-그-밖) | 제품 · 호수 · 색 수집 | 가입 없음 | `CATALOG_CONTACT` |

## 1. SSAFY GMS — LLM

SSAFY가 제공하는 LLM 중계 서비스. 원래 API(Anthropic · Google)와 요청 형식이 같고 **주소와 키만 바꾼다**.

| 항목 | 내용 |
| --- | --- |
| 발급 | SSAFY GMS 화면에서 팀 키 발급 (`S15P32A306-...` 형식) |
| Claude 주소 | `https://gms.ssafy.io/gmsapi/api.anthropic.com` (`LLM_BASE_URL`) |
| Gemini 주소 | `https://gms.ssafy.io/gmsapi/generativelanguage.googleapis.com` (`GEMINI_BASE_URL`) |
| 키 헤더 | Claude `x-api-key`(Anthropic SDK), Gemini `x-goog-api-key` |

| 쓰는 곳 | 모델 | 용도 | 키를 넣는 곳 |
| --- | --- | --- | --- |
| AI 서버 | `claude-haiku-5-5` (`LLM_MODEL`) | 단계 설명 · 가이드 문장 | `/mairor/ai/GMS_API_KEY` |
| AI 화장품 수집기 | `claude-sonnet-4-6` (`CATALOG_LLM_MODEL`) | 사진 분류 · 종류 추정 · 공식 홈 검색 | 수집기 `.env` |
| 노트북 처리기 | Gemini | 영상에서 단계 · 제품 찾기 | `video-processor/.env` `GMS_API_KEY` |
| BE worker | `gemini-2.5-flash` (`GEMINI_MODEL`) | 노트북 없이 돌 때 단계 추출 | `/mairor/prod/GEMINI_API_KEY` |

- GMS 키가 없으면 AI 서버는 기동 단계(`deploy-ai.sh` 필수값)에서 멈춘다. worker의 Gemini 키가 없으면 그 단계가 `LLM_UNAVAILABLE`로 실패한다.
- 호출 기록은 Phoenix(https://k15a306.p.ssafy.io/phoenix)에서 본다.

## 2. Google OAuth (소셜 로그인)

| 단계 | 내용 |
| --- | --- |
| 1 | [Google Cloud Console](https://console.cloud.google.com) → 프로젝트 만들기 |
| 2 | API 및 서비스 → **OAuth 동의 화면**: 외부, 범위 `openid` · `email` · `profile`. 테스트 상태면 등록한 테스트 사용자만 로그인된다 |
| 3 | 사용자 인증 정보 → **OAuth 클라이언트 ID** → 웹 애플리케이션 |
| 4 | 승인된 리디렉션 URI에 환경마다 등록 |
| 5 | 클라이언트 ID · 보안 비밀을 Parameter Store에 넣는다 |

| 환경 | `GOOGLE_REDIRECT_URI` |
| --- | --- |
| 운영 | `https://mairor.co.kr/api/v1/users/oauth/google/callback` |
| 로컬 | `http://localhost:3000/api/v1/users/oauth/google/callback` |

- 리디렉션 주소는 **FE 주소의 `/api` 경로**다. BE 포트(`:8080`)로 두면 쿠키가 FE 호스트에 붙지 않는다.
- 셋 중 일부만 있으면 BE가 뜨지 않는다. prod에서는 셋 다 없어도 뜨지 않는다.
- 회원은 Google `sub`로 찾는다(`user_identities`). 같은 이메일의 다른 계정과 자동으로 연결하지 않는다.

## 3. Gmail SMTP (인증 메일)

| 단계 | 내용 |
| --- | --- |
| 1 | 프로젝트 전용 Gmail 계정을 만든다 |
| 2 | Google 계정 → 보안 → **2단계 인증** 켜기 |
| 3 | 보안 → **앱 비밀번호** 만들기 (16자리) |
| 4 | `MAIL_ENABLED=true`, `MAIL_USERNAME=<Gmail 주소>`, `MAIL_PASSWORD=<앱 비밀번호>` |

- SMTP `smtp.gmail.com:587` STARTTLS(기본값). 보내는 사람 이름 `Mairor`.
- 계정 비밀번호가 아니라 **앱 비밀번호**를 넣는다.
- `MAIL_ENABLED=false`면 dev는 인증번호를 서버 로그에만 남기고, prod는 발송이 항상 실패한다.
- Gmail 하루 발송 한도(약 500통)가 있다.

## 4. YouTube

### YouTube Data API v3 (BE)

| 단계 | 내용 |
| --- | --- |
| 1 | GCP 콘솔(위와 같은 프로젝트 가능) → 라이브러리 → **YouTube Data API v3** 사용 설정 |
| 2 | 사용자 인증 정보 → **API 키** 만들기 → API 제한을 YouTube Data API v3로 |
| 3 | `/mairor/prod/YOUTUBE_API_KEY` |

- 기본 할당량 하루 10,000 단위. 검색 1회 100단위라 검색이 가장 많이 쓴다.
- 키가 없으면 BE는 뜨지만 영상 검색이 503, 영상 선택이 502로 실패한다.
- 영상 메타는 YouTube 정책(30일)에 맞춰 25일마다 다시 받는다(worker 정리 작업).

### 영상 원본 받기 (yt-dlp, 노트북)

- 가입이 없다. `video-processor/requirements.txt`의 `yt-dlp`로 받는다.
- **AWS IP에서는 유튜브가 봇으로 판단해 막는다.** 그래서 영상 받기 · 단계 찾기 · 프레임 뽑기를 팀 맥북이 한다([01 § 5.1](01-포팅매뉴얼.md#51-영상-전처리기는-노트북에서-돈다)).
- 막혔을 때 실패 코드 `DOWNLOAD_REJECTED`(재시도 안 함).

## 5. AWS

계정 하나, 서울 리전 `ap-northeast-2`. 자원 이름은 모두 `mairor-` 접두사, 태그 `Project=mairor`.

| 서비스 | 자원 | 용도 |
| --- | --- | --- |
| EC2 | `mairor-app`, `mairor-ai` | BE 서버, AI 서버 |
| ALB · ACM · Route 53 | `mairor-alb`, `mairor.co.kr` | HTTPS 입구, 인증서, 도메인 |
| RDS | `mairor-db` (PostgreSQL 17) | DB |
| S3 | `mairor-prod-media` | 영상 프레임(`videos/`), 사진(`photos/`), 카탈로그 결과(`catalog-runs/` · `catalog-sites/`) |
| ECR | `mairor-nginx` · `mairor-backend` · `mairor-ai` · `mairor-deploy` | 이미지 (최근 10개) |
| SSM | Parameter Store `/mairor/prod/*` · `/mairor/ai/*`, Session Manager, Run Command | 비밀값, 서버 접속, CI 배포 |
| SQS · ECS Fargate | 화장품 수집 큐 (`CATALOG_COLLECT_QUEUE_URL`), 수집 워커(`ai/Dockerfile.collector`) | DB에 없는 화장품 수집 요청 처리 |
| CloudWatch Logs | `/mairor/prod` | 컨테이너 로그 30일 |
| IAM | 사용자 `mairor-ci-deploy` | CI 전용. ECR push + 태그 `Project=mairor` EC2에 SSM 명령만 |

- **키 교체**: IAM에서 새 키 → GitLab 변수 교체 → master 파이프라인 성공 확인 → 옛 키 비활성화 · 삭제.
- **노트북 처리기의 S3 키**는 `mairor-prod-media` 업로드 권한만 있으면 된다.
- 비용 어림값과 정지 · 재개 방법은 [deploy/README](../deploy/README.md#비용--정지--재개-s15p31a306-416).

## 8. 서비스 간 인증 토큰

외부 서비스는 아니지만, 새 환경을 만들 때 **직접 만들어 양쪽에 같은 값을 넣어야 하는** 값이다. `openssl rand -hex 32`로 만든다.

| 토큰 | 헤더 | 넣는 곳 |
| --- | --- | --- |
| `INTERNAL_API_TOKEN` | `X-Internal-Token` | BE `/mairor/prod/INTERNAL_API_TOKEN`, 이 API를 부르는 쪽(카탈로그 수집 워커 · 운영자 도구) |
| `PROCESSOR_API_TOKEN` | `X-Processor-Token` | BE `/mairor/prod/PROCESSOR_API_TOKEN`, 노트북 `video-processor/.env` |
| `EMAIL_VERIFICATION_SECRET` | – (인증번호 해시) | BE만 |

비우면 해당 내부 API가 모두 401이다(앱은 뜬다).
