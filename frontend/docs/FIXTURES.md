# 픽스처

미리보기·추적 화면을 카메라·백엔드 없이 확인하기 위한 예시 데이터(`public/fixtures/`)다. `npm run fixtures`로 다시 만든다 (손으로 고치지 않는다). 스크립트는 Node 22.18 이상에서 돌아가고, 낮은 버전이면 바로 알려 준다 (`.nvmrc` 기준 24). 판정 기준값은 추적기 코드(`tracking-rules.ts`, `visibility.ts`)에서 그대로 읽는다.

- 얼굴 데이터: `FaceFrame` (`src/features/face/types.ts`, `meshVersion: "v1"`)
- 레이어: `LayerSet` (`src/features/overlay/types.ts`)
- 가이드: `GuideSet` (`src/features/guide/types.ts`)
- 출처: `shared/face-mesh/`의 캐노니컬 얼굴 메시 UV를 정면 얼굴 랜드마크로 쓴 합성 데이터. 실제 사람 얼굴이 아니다
- 확인 화면: `/debug/overlay`에서 얼굴과 레이어를 골라 합성 결과를 본다 (`?face=turned-left&layers=lip-only`처럼 주소로도 고를 수 있다)

## 얼굴 (`faces/`)

| 파일               | 상태                                                                                    | 예상 화면 동작                                                          |
| ------------------ | --------------------------------------------------------------------------------------- | ----------------------------------------------------------------------- |
| `front.json`       | 정면, `tracking`                                                                        | 화장 레이어·가이드 모두 표시                                            |
| `turned-left.json` | `yaw` 0.8 (왼쪽으로 돌림), 왼쪽 눈·입이 돌아가 `degraded`                               | 화장 레이어·가이드 모두 숨김                                            |
| `close-up.json`    | 가까이 다가가 아랫입술·턱이 화면 밖, 립 `inFrameRatio` 0.75지만 두 눈이 보여 `tracking` | 립 레이어·가이드는 화면 밖이라 숨김, 나머지 화장 레이어·가이드는 표시   |
| `far.json`         | 얼굴 폭이 화면의 약 30%, `tracking`                                                     | 화장 레이어·가이드 모두 표시. 가이드 선·점은 최소 크기 이상으로 보임    |
| `blink-hold.json`  | 눈 감음, `hold`                                                                         | 직전에 보이던 경우에만 직전 위치로 유지. 확인 화면에서 처음 고르면 숨김 |
| `lost.json`        | `lost`                                                                                  | 화장 레이어·가이드 모두 숨김                                            |

- `trackingState`는 추적기와 같은 규칙으로 정한다. 주요 부위(양쪽 눈·입술 바깥) 중 화면 안에 있고(0.9 이상) 카메라 쪽을 향한 부위가 2개 미만이면 `degraded`다.
- 추적이 불안정(`degraded`)하거나 놓치면(`lost`) 화장 레이어와 가이드를 모두 숨긴다 (CAMERA-004).

## 레이어 (`layers/`)

| 파일                | 내용                                         | 예상 화면 동작                                                         |
| ------------------- | -------------------------------------------- | ---------------------------------------------------------------------- |
| `sample.json`       | 파운데이션·아이섀도·아이라인(양쪽)·블러셔·립 | 배열 순서대로 겹쳐 표시                                                |
| `lip-only.json`     | 립 하나                                      | 입술만 표시, 입 안쪽은 빔                                              |
| `empty.json`        | 레이어 없음                                  | 영상만 표시. `/preview`에서는 "그릴 수 있는 화장 레이어가 없어요" 안내 |
| `no-color.json`     | 립 `color: null`                             | 립은 그리지 않고 파운데이션만 표시                                     |
| `missing-mask.json` | 블러셔 마스크 파일 없음                      | 블러셔는 경고를 남기고 빼고 립만 표시                                  |

- UV 마스크(`layers/masks/`)는 512 × 512, 8비트 흑백 PNG이고 색 프로필이 없다. 입·눈 안쪽은 0이다
- 블러셔 마스크는 볼 영역 위쪽 점(오른쪽 123, 116, 117, 118, 101)과 50으로 만든 샘플이다 (왼쪽은 대칭)

## 가이드 (`guides/`)

| 파일              | 내용                                                                                      | 예상 화면 동작                                                                              |
| ----------------- | ----------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------- |
| `sample.json`     | 앱의 기본 가이드(9개 부위)를 파일로 내보낸 것, `source: template`                         | `/debug/tutorial?guides=/fixtures/guides/sample.json`에서 단계마다 점선 영역·선·화살표 표시 |
| `empty.json`      | 단계 없음                                                                                 | "이 영상에는 가이드가 없어요" 안내                                                          |
| `right-only.json` | 기본 가이드에서 본인 기준 오른쪽 도형만 남긴 것 (가운데·왼쪽 도형이 있는 단계는 오른쪽만) | 거울 화면이라 화면 **오른쪽** 얼굴에만 표시. 왼쪽에 보이면 좌우 반전이 잘못된 것            |

- `/debug/overlay?step=blush`처럼 단계 이름(`stepId`)이나 순서(0~8)로 카메라 없이 기본 가이드를 부위별로 볼 수 있다
- `?guides=/fixtures/guides/right-only.json`을 붙이면 기본 가이드 대신 그 파일을 쓴다. 단계 수가 달라 순서가 어긋나므로 단계 이름으로 고른다

## 가이드 영역 (`guide-areas/`)

AI가 넘기는 가이드 영역 형식(`shared/guide-area`)이다. `npm run fixtures`가 만들고, 모두 공유 JSON Schema를 통과한다.

| 파일            | 내용                                                                                                                                | 예상 화면 동작                                                                                                                                                                                             |
| --------------- | ----------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `local_01.json` | AI 샘플(`ai/samples/local_01/guide_area.json`) 그대로. 단, 샘플의 `extracted` 좌표는 형식 예시라 같은 부위의 랜드마크 테두리로 바꿈 | `/tutorial`이 단계 ID로 찾아 그림. 립 `s17`은 입술 테두리, `s19`는 영역 없음 안내, 나머지는 기본 가이드. 하위 단계 전환을 보려고 아이섀도 `s10`은 눈두덩(눈 빼기) → 기본 영역 → 애교살 세 하위 단계로 나눔 |
| `sample.json`   | 상태 네 가지, 한 단계 안의 하위 단계 전환(`s4`), 빼는 영역(아이섀도의 눈, 립의 입 안)                                               | `/debug/tutorial?area=/fixtures/guide-areas/sample.json`에서 하위 단계마다 상태와 안내 표시                                                                                                                |
