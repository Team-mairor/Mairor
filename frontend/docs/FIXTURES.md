# 픽스처

미리보기·추적 화면을 카메라·백엔드 없이 확인하기 위한 예시 데이터(`public/fixtures/`)다. `npm run fixtures`로 다시 만든다 (손으로 고치지 않는다). 스크립트는 Node 22.18 이상에서 돌아가고, 낮은 버전이면 바로 알려 준다 (`.nvmrc` 기준 24). 판정 기준값은 추적기 코드(`tracking-rules.ts`, `visibility.ts`)에서 그대로 읽는다.

- 얼굴 데이터: `FaceFrame` (`src/features/face/types.ts`, `meshVersion: "v1"`)
- 레이어: `LayerSet` (`src/features/overlay/types.ts`)
- 가이드: `GuideSet` (`src/features/guide/types.ts`)
- 출처: `shared/face-mesh/`의 캐노니컬 얼굴 메시 UV를 정면 얼굴 랜드마크로 쓴 합성 데이터. 실제 사람 얼굴이 아니다
- 확인 화면: `/debug/overlay`에서 얼굴과 레이어를 골라 합성 결과를 본다 (`?face=turned-left&layers=lip-only`처럼 주소로도 고를 수 있다)

## 얼굴 (`faces/`)

| 파일               | 상태                                                                                    | 예상 화면 동작                                                          |
| ------------------ | --------------------------------------------------------------------------------------- | ----------------------------------------------------------------------- |
| `front.json`       | 정면, `tracking`                                                                        | 화장 레이어·가이드 모두 표시                                            |
| `turned-left.json` | `yaw` 0.8 (왼쪽으로 돌림), 왼쪽 눈·입이 돌아가 `degraded`                               | 화장 레이어·가이드 모두 숨김                                            |
| `close-up.json`    | 가까이 다가가 아랫입술·턱이 화면 밖, 립 `inFrameRatio` 0.75지만 두 눈이 보여 `tracking` | 립 레이어·가이드는 화면 밖이라 숨김, 나머지 화장 레이어·가이드는 표시   |
| `far.json`         | 얼굴 폭이 화면의 약 30%, `tracking`                                                     | 화장 레이어·가이드 모두 표시. 가이드 선·점은 최소 크기 이상으로 보임    |
| `blink-hold.json`  | 눈 감음, `hold`                                                                         | 직전에 보이던 경우에만 직전 위치로 유지. 확인 화면에서 처음 고르면 숨김 |
| `lost.json`        | `lost`                                                                                  | 화장 레이어·가이드 모두 숨김                                            |

- `trackingState`는 추적기와 같은 규칙으로 정한다. 주요 부위(양쪽 눈·입술 바깥) 중 화면 안에 있고(0.9 이상) 카메라 쪽을 향한 부위가 2개 미만이면 `degraded`다.
- 추적이 불안정(`degraded`)하거나 놓치면(`lost`) 화장 레이어를 숨긴다. 가이드는 `degraded`일 때 `usableRegions`에 든 부위만 그리며, 픽스처에는 이 값이 없어 모두 숨긴다 (CAMERA-004).

## 레이어 (`layers/`)

| 파일                | 내용                                         | 예상 화면 동작                                                         |
| ------------------- | -------------------------------------------- | ---------------------------------------------------------------------- |
| `sample.json`       | 파운데이션·아이섀도·아이라인(양쪽)·블러셔·립 | 배열 순서대로 겹쳐 표시                                                |
| `lip-only.json`     | 립 하나                                      | 입술만 표시, 입 안쪽은 빔                                              |
| `empty.json`        | 레이어 없음                                  | 영상만 표시. `/preview`에서는 "그릴 수 있는 화장 레이어가 없어요" 안내 |
| `no-color.json`     | 립 `color: null`                             | 립은 그리지 않고 파운데이션만 표시                                     |
| `missing-mask.json` | 블러셔 마스크 파일 없음                      | 블러셔는 경고를 남기고 빼고 립만 표시                                  |

- UV 마스크(`layers/masks/`)는 512 × 512, 8비트 흑백 PNG이고 색 프로필이 없다. 입·눈 안쪽은 0이다
- 블러셔 마스크는 볼 영역 위쪽 점(오른쪽 123, 116, 117, 118, 101)과 50으로 만든 샘플이다 (왼쪽은 대칭)

## 가이드 (`guides/`)

| 파일              | 내용                                                                                      | 예상 화면 동작                                                                              |
| ----------------- | ----------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------- |
| `sample.json`     | 앱의 기본 가이드(9개 부위)를 파일로 내보낸 것, `source: template`                         | `/debug/tutorial?guides=/fixtures/guides/sample.json`에서 단계마다 점선 영역·선·화살표 표시 |
| `empty.json`      | 단계 없음                                                                                 | "이 영상에는 가이드가 없어요" 안내                                                          |
| `right-only.json` | 기본 가이드에서 본인 기준 오른쪽 도형만 남긴 것 (가운데·왼쪽 도형이 있는 단계는 오른쪽만) | 거울 화면이라 화면 **오른쪽** 얼굴에만 표시. 왼쪽에 보이면 좌우 반전이 잘못된 것            |

- `/debug/overlay?step=blush`처럼 단계 이름(`stepId`)이나 순서(0~10)로 카메라 없이 기본 가이드를 부위별로 볼 수 있다
- `?guides=/fixtures/guides/right-only.json`을 붙이면 기본 가이드 대신 그 파일을 쓴다. 단계 수가 달라 순서가 어긋나므로 단계 이름으로 고른다

## 가이드 영역 (`guide-areas/`)

AI가 넘기는 가이드 영역 형식(`shared/guide-area`)이다. `npm run fixtures`가 만들고, 모두 공유 JSON Schema를 통과한다.

### 카메라 없이 하위 단계 확인

`/debug/overlay?area=/fixtures/guide-areas/local_01.json`에서 합성 얼굴 위에 AI 영역을 그린다. 카메라 권한과 API 서버는 필요 없다.

- 단계·하위 단계 선택 또는 이전·다음으로 모든 하위 단계를 순서대로 확인한다. 기본은 첫 하위 단계이고, 이전·다음은 단계 경계도 넘어간다.
- `?step=s10&subStep=s10-2`로 특정 하위 단계를 바로 연다. 두 값은 ID 또는 0부터 센 순서다. 없는 ID는 선택 안내만 표시한다.
- `extracted`는 받은 영역과 시작점·방향 화살표를 함께 표시하고, 화살표가 없으면 영역만 표시한다. `template`은 기본 가이드 키에 맞는 도형을 표시한다. `notApplicable`·`failed`는 도형 없이 상태·안내·사유를 표시한다.
- 얼굴 픽스처를 바꿔 고개 돌림·근접·원거리·hold·lost 상태에서 표시를 확인한다. hold는 같은 하위 단계가 직전에 보였을 때만 유지된다.
- 영역 모드에서는 화장 레이어를 기본으로 비워 가이드만 본다. `?layers=lip-only`처럼 지정하거나 화면에서 바꾸면 함께 볼 수 있다.
- `?area=`와 `?guides=`가 함께 있으면 AI 영역을 사용하며, 기본 위치는 앱 기본 가이드에서 가져온다. 기존 `?guides=`·`?step=` 확인은 그대로 쓴다.
- 네 상태와 눈·입 안 제외 영역은 `/debug/overlay?area=/fixtures/guide-areas/sample.json`으로 확인한다. 빈 파일은 빈 가이드 안내, 조회·형식 오류는 오류 문구를 표시한다.

합성 얼굴 확인은 데이터·표시 동작 검사용이다. 실제 얼굴 정렬·실기기 성능·하프미러 가독성은 기기에서 별도로 확인한다.

| 파일            | 내용                                                                                                                                                          | 예상 화면 동작                                                                                                                                                                                                                                                                                                    |
| --------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `local_01.json` | AI 샘플(`ai/samples/local_01/guide_area.json`)을 바탕으로 만들고, `extracted` 영역 좌표만 화면에서 알아볼 수 있는 같은 부위 랜드마크 테두리로 바꿈            | `/tutorial`이 단계 ID로 찾아 그림. 립 `s17`은 입술 테두리, `s19`는 영역 없음 안내, 나머지는 기본 가이드. 하위 단계 전환을 보려고 아이섀도 `s10`은 눈두덩(눈 빼기) → 기본 영역(위아래 · 위 · 아래) → 애교살 다섯 하위 단계로 나눔. 하위 단계마다 보려면 `/debug/tutorial?area=/fixtures/guide-areas/local_01.json` |
| `sample.json`   | 상태 네 가지, 한 단계 안의 하위 단계 전환(`s4`·`s6`), 빼는 영역(아이섀도의 눈, 립의 입 안), 눈 하나에 도형 두 개인 아이라인(`s6-2`, 앞머리 쪽 띠와 눈꼬리 띠) | `/debug/tutorial?area=/fixtures/guide-areas/sample.json`에서 하위 단계마다 상태와 안내 표시                                                                                                                                                                                                                       |

## 기본 가이드 비교

`/debug/guide-compare`에서 블러셔·눈썹의 변경 전과 현재 기본값을 비교한다.
개발 서버에서는 기본으로 켜지며 `GUIDE_EXPERIMENTS=0`으로 끈다.
빌드에 포함하려면 `DEV_TOOLS=1 GUIDE_EXPERIMENTS=1 npm run build`를 사용한다.
실험을 끈 빌드에서는 비교 라우트·코드·모델·WASM·비교 픽스처를 제외한다.

| 파일                            | 용도                        | 생성 방법                  |
| ------------------------------- | --------------------------- | -------------------------- |
| `guides/compare-baseline.json`  | `7054f7c` 기준 변경 전 모양 | 고정, 재생성하지 않음      |
| `guides/compare-candidate.json` | 현재 블러셔·눈썹 기본값     | `npm run fixtures:compare` |

- 합성 얼굴 또는 카메라 하나로 변경 전·현재·좌우 비교를 선택한다. 화면 고정은 영상과 좌표를 함께 멈춘다.
- 합성 얼굴의 hold·lost·복구 순서로 표시 이력을 검사한다. 회전 픽스처는 숨김 검사 전용이다.
- 블러셔는 볼 범위의 타원과 기존 시작점·방향을, 눈썹은 한쪽당 가는 결 40개를 표시한다.
- 실기기에서는 위치·회전·거리·추적 복구·하프미러 가독성을 확인한다. 비교 화면은 렌더러 두 개를 사용한다.

눈썹 모델 준비·사용법·출처는 [눈썹 인식 실험](BROW_EXPERIMENT.md)을 참고한다.
